## 文档说明

五份基线文档各管一个真相，本文是第六份：**执行真相**——文档管「为什么 / 是什么」，本清单管「做到哪一步」。任务完成时在「证据」列补提交号 / 截图 / 文档段落，不另开新文档记进度。

- 状态记号：☐ 未开始 · ◐ 进行中 · ☑ 完成（有证据）
- 每条任务给出处（文档 § ），改任务先改出处文档，再改这里。
- 工程规矩（门禁、生成文件、i18n 十语言）以上游仓 `AGENTS.md` / `CONTRIBUTING.md` 为准，清单不复制。
