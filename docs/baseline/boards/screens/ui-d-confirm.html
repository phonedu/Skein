这一屏的规矩
1三栏固定：待确认列表 / diff / 证据。顺序不变，用户知道东西在哪一栏。
2证据必须在场：没有来源链接的提议不成立——原始笔记优先于 Agent 摘要。
3只有三个动作：确认、驳回、稍后。批量确认被禁止，30 分钟后失效。
4驳回也要写回：驳回的理由会进历史，避免同一个提议反复冒出来。
