Textus · 四款皮肤对照

同一块屏、同一份内容、同一套几何（窗口栏 44 · 轨道 56 · 侧栏 316 · 树行 28 · 控件 34 · 圆角 12/8/4 · 4px 栅格）， 四列之间只有调色板不同。A 层修法——三段明度（背景 < 面板 < 卡片）、强调色系统（焦点环 / 选中 / 链接 / 开关）、 暗色「越浮越亮」、次要文字过 4.5:1——在四款中同样生效，用来公平对比。推导比例沿用设计语言 §3.1 （边线 = 墨 16%、悬停 = 墨 7%、选中 = 强调色 13%），右列控件条为原尺寸近观。几何、密度、动效一概不动：这是换肤，不是重排。
