> 状态：v1.0（2026-11-17 立项，与《界面现状盘点》v1.0 同基线 `cfacf4c2`）
> 规范的家：目标 = [04-boards/](../04-boards/README.md) 十屏；裁决 =《界面改造方案》§4；机制复用 =《改造方案》§7.7
> 关闭时处置：十屏全部落地后归档；行为变化先改本表再动代码（AI协作纪律 §五）

> 读法：逐屏回答「现状有什么 → 画板要它变成什么 → 落在哪（复用什么 / 新增什么）→ 行为变什么」。现状细节见《界面现状盘点》；任务进度见《改造任务清单》C 组；分组与数值以画板 HTML 源为准，本表不复制数值。

## 总原则

1. **画板是目标，现状是宿主**：改界面 = 把实现做成画板的样子，不做第三种设计。
2. **复用优先**（《改造方案》§7.7）：侧栏页签注册、命令注册、Webview 视图、现有 AI 容器、抽屉与 ActionSheet——能复用不新建。
3. **写操作三件套**（§7.6）：必须卡片 + diff + 确认；归档代替删除。
4. **数据依赖**照《任务清单》§4：壳先行，数据屏随 D1。

## 已裁的行为红线（别在实现里翻案）

- 组件库 Base UI；设置页是浮层不占轨；编辑区单岛平铺（裁决 12）；
- 写操作必须卡片 + diff + 确认；归档代替删除；自定义首页 / 拖拽看板 / 图谱视图 / 多套布局主题 / 墨契式浮层格式条先不做（《任务清单》§4）；
- 主题基色 = 纸 `#fbf8f2` / 墨 `#241f19` / 火 `#b0531f`（裁决 14/16，护栏 `theme-palette.test.ts` + 对比度测试）。
