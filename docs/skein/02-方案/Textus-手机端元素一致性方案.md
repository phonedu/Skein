# Textus 手机端全局元素一致性方案

> **状态**：**草稿，待拍板（2026-11-18）**。拍板后作为「统一刷一遍」的施工单与验收标准；未拍板前不改任何既有样式。
> **范围**：`data-window-chrome="mobile"` 下的全部界面（L0–L5 已逐屏过完日/夜两轮）。桌面沿用上游自己的规范，本方案不覆盖。
> **真值来源**：token 表（`src/engine/tokens/`）与已验收的手机样式（`src/phone/`、`src/features/settings/settings-phone.css`、`src/mobile/styles/`）。本文只是把已落地的散点收拢成规则，不发明新值。
> **冲突时**：《界面改造方案》的裁决优先于本文；本文「待裁项」一节列出与既有裁决冲突的地方，等用户拍板。

## 0. 一句话

**同一张纸上的三件事：纸墨一色（颜色）、发丝分域（线与间距）、火色只标「正在发生」（强调）。** 夜里的界面是同一张纸在夜里，不是另一套皮肤。

## 1. 三条原则

| # | 原则 | 含义 |
| --- | --- | --- |
| 1 | 纸墨一色 | 底色、卡片、输入槽都取纸的色阶；不用纯白、不用灰蓝面板；强调色只有一个。 |
| 2 | 发丝分域 | 用 1px 发丝线与间距分层；不用阴影堆叠、不用色块切块。阴影只给真正浮起的东西（浮层、FAB、Toast）。 |
| 3 | 火只标正在发生 | `--ui-accent` 只用于：主行动（FAB / 主 CTA / 当前选中）、正在发生（火点、发送/插入的进行中态）、致命/危险走 `--ui-danger`。其余强调用墨色（`--ui-text`）或静墨（`--ui-muted`）。 |

## 2. 色阶

全部颜色只从下列 token 取；**组件里禁止出现字面色值**（`theme-reach` 测试已在守）。

| Token | 亮（默认纸） | 暗（夜纸） | 用途 | 禁止 |
| --- | --- | --- | --- | --- |
| `--ui-bg` | `#fbf8f2` | `#1f1b16` | 页面底、卡片底、浮层底 | 当输入框底 |
| `--ui-surface` | `= --ui-bg` | `= --ui-bg` | 卡片/输入槽与纸面的「同一张纸」；需要区分时靠发丝线与 `--ui-subtle` | — |
| `--ui-subtle` | 墨 4% 混纸 | 同 | 折叠块等次级面板 | 大面积铺底 |
| `--ui-text` | `#241f19` | `#e8ddc9` | 正文、标签、主按钮底（`--ui-primary = --ui-text`） | 次要信息 |
| `--ui-muted` | `#5f574b` | `#9c8f77` | 元信息、说明、占位符、图标默认色 | 正文 |
| `--ui-border` | 墨 16% 混纸 | 同 | 发丝线、卡片描边、输入描边 | 分隔大块 |
| `--ui-accent` | `#b0531f` | `#d98b52` | 火：主行动、选中、正在发生 | 正文、装饰 |
| `--ui-accent-text` | accent 80% 混墨 | 同 | 火色的文字形态（危险之外的可点文字） | 大面积 |
| `--ui-danger` | `#be364b` | `#f18b99` | 破坏性动作（红字/红图标） | 普通强调 |
| `--ui-warning` | `#9a6212` | `#e3b35f` | 警告条、提示 | 装饰 |
| `--ui-success` | `#24734d` | `#79cba1` | 成功态 | 选中态 |
| `--ui-hover` | 墨 7% | 同 | 按压/悬停底 | 选中 |
| `--ui-selected` | accent 13% | 同 | 列表选中行（当前库、服务商） | 按钮 |
| `--ui-overlay` | `rgb(20 27 40 / 30%)` | `rgb(0 0 0 / 48%)` | 浮层遮罩 | 页面底 |

**主题**：`--ui-*` 全部由文档主题（`--doc-*`）派生（`base.css`），所以选森林/纸墨主题时整窗一起变色——这是设计行为，不是 bug。夜间的所有 token 在 `base.css` 与 `ds-base.css` 成对定义，新加颜色必须两处都给。

## 3. 字号与字重

角色制，禁止裸 px（`--text-caption` 的 12px 例外项见裁决 15）：

| 角色 | 手机值 | 用途 | 字重 |
| --- | --- | --- | --- |
| `--text-large-title` | 34 | 桌面级大标题（手机不用） | 700 |
| `--text-title` | 17 | 顶栏栏名（文件名 / 页名）、对话框标题、编辑页 h2 级 | 600 |
| `--text-body` | 17 | 行名、文章正文、输入文字、sheet 行 | 400（行名 400，栏名 600） |
| `--text-secondary` / `--text-control` | 15 | 按钮文字、控件值、提示行 | 400–600 |
| `--text-footnote` | 13 | 分节小标题、行说明（desc/hint）、Toast | 400（分节 600 + 0.08em 字距） |
| `--text-caption` | 12 | **只给元信息**（行尾日期/篇数、版本号、空态 hint? 否） | 400 |
| 空态标题 | 20（字面值，PhoneHome/AI 空态） | 空库/AI 登录卡标题 | 650 |

行高：正文 1.75–1.8（编辑页）；行 1.35–1.5；说明 1.4–1.5。字距：分节小标题 0.08em；空态标题 0.01em。

## 4. 间距与尺寸

手机端的 `--space-*` 阶梯（`ui-sizes.css` 移动块）：**4 · 6 · 10 · 14 · 20 · 28**（写值；界面随主题字号缩放走 `--ui-text-scale`，组件里只写 token）。

| 量 | 值 | 用在哪 |
| --- | --- | --- |
| 页面左右边 | `--space-4` | 所有页面 body、卡片外缘 |
| 行内距（纵/横） | `--space-1` / `--space-4` | 卡片里的行：4 上/下，14 左/右 |
| 发丝线内缩 | 与行文字齐（`--space-4`） | 卡片内行与行之间 |
| 分节标题上/下 | `--space-4` / `--space-2` | 分节小标题到上一块 / 到下卡片（实测 16 / 8） |
| 卡片组间距 | `--space-6` | 一页里两组之间 |
| 行高（最小） | **56**（样式写 62，chrome-scale 10/11 折算） | 列表行、设置行、sheet 行、服务商行 |
| 触控最小 | 44；主控件 48 | 图标按钮 40–48、圆点 34 热区（InfoTip） |
| FAB | 56 圆 | 家页右下 |
| 顶栏 | 48 + 安全区 | 家页/编辑页/AI 页 |
| Sheet 圆角 | 22 | 底部面板组、取消键 |
| 卡片圆角 | 14（`--shape-m`） | 所有卡片；图标 chip 8（`--shape-s`）；输入槽 14；对话框 14 |

> 写值 vs 绘制值：`src/` 样式里的长度会被构建期乘 `--chrome-scale`（手机 10/11）；**token 不缩放**。因此「样式里写 62」=「屏幕上 56」。新样式沿用同一套写法，不手算。

## 5. 行（Row）

**解剖**（设置页、列表、sheet 通用）：

```
[可选图标 chip 32]  行名 17/400 ……………………………… [控件：开关/值胶囊/chevron]
                    说明 13/muted（可选，整行宽）
```

| 规则 | 定式 |
| --- | --- |
| 行高 | 最小 56；内容多时撑高 |
| 纵向内距 | 4；说明行可加到 10 |
| 名称+控件同排 | 名称 `flex: 1 1 auto; min-width: 0`，控件不换行到第二排（开关行 `nowrap`） |
| 带说明的行 | 名称+说明占满整行，控件在下方**右对齐**（`:has(.settings-row-desc)` 分流） |
| 行间线 | 1px `--ui-border`，左右各内缩 14；**不用** `border-top` 简写（WebView 老内核会整条丢弃 → 墨色粗框） |
| 行尾动作 | 文字型动作静墨 13–15；破坏性 `--ui-danger` |
| 帮助「?」 | 跟在名称**同一行**文字后面（inline-flex，-3px 垂直对齐） |
| 选中行 | `--ui-selected` 淡底（服务商、当前库）；不加左侧粗条 |
| 嵌套行（折叠 details 内） | 与普通行同内距、同发丝线 |

## 6. 卡片（Card）

| 项 | 定式 |
| --- | --- |
| 底/边/角 | `--ui-surface` + 1px `--ui-border` + 14 圆角 + `overflow: hidden` |
| 卡外 | 分节小标题（13/600/0.08em/muted）在卡片**外**，上 16 下 8；同页卡片间距 24 |
| 卡内 | 只有行；行与行之间内缩发丝线；卡自身不加内边距（行的内距承担） |
| 首页列表 | 行带 32px 图标 chip（8 圆角、墨 6% 底、静墨图标）；子页行不带图标 chip |
| 空态 | 卡内居中：64px 火色 tint chip + 20/650 标题 + 13–15 muted 说明（+ 主 CTA，视场景） |

## 7. 按钮与控件

| 种类 | 形状 | 用色 | 尺寸 |
| --- | --- | --- | --- |
| 主行动（CTA：登录、新建文件、空态行动） | 胶囊 | `--ui-primary` 底 + `--ui-on-primary` 字（夜间自动反色） | 高 44–48，横内距 20 |
| FAB | 56 圆 | `--ui-accent` 底 + `--ui-paper` 字 | 右下，距底 24 + 安全区 |
| 值控件（设置里的 Select / 值胶囊） | 胶囊（裁决 17 保留） | 透明底 + 1px border；值 15 | 高 40–44 |
| 行内文字动作（导入技能…、制作你的主题、收起） | 无底无框 | `--ui-muted`，13 | 40 高触区 |
| 危险文字动作（删除、清空） | 无底 | `--ui-danger` | 同文字动作 |
| 图标按钮 | 40–48 方/圆，无边框 | `--ui-text`（顶栏）/ `--ui-muted`（工具条） | — |
| 开关 | 胶囊轨道 | 开 = `--ui-accent`，关 = 墨 18% | 43×26 |
| 分段控件 | 胶囊轨道 + 胶囊滑片 | 选片表面 + 墨字，轨道墨 8% | 高 40 |
| Sheet 行 | 56 高，图标胶囊 34/8 | 名称墨，图标胶囊墨 6% 底静墨字；`danger` 红；`fire` 火（收集箱） | — |
| 对话框按钮 | 48 高文字行，发丝线分格 | 常规 `--ui-accent-text`；危险 `--ui-danger` | 2 个并排，3+ 个纵向 |
| Badge / chip | 胶囊 | 墨 8% 底，静墨字 | 高 20–22 |

> **待裁 A**：裁决 17「动作按钮 = `--shape-s`（8px）圆角矩形、胶囊只给 chips/徽章/设置值控件」与现状冲突——当前主行动（登录/新建文件等）是胶囊，画板与参考应用也是胶囊。建议：**把裁决 17 的 8px 限定为桌面与图标按钮；手机主行动维持胶囊**（与 FAB、Toast、Sheet 同一语言）。拍板前不动。

## 8. 输入

| 种 | 定式 |
| --- | --- |
| 搜索槽（家页/设置） | `--ui-surface` 底 + 1px `--ui-border` + 14 圆角 + 顶部 1px 内高光（surface 60% 混透明）；高 46（写 50）；占位 muted 72% |
| 聚焦 | 描边转 `accent 45% × border` 混合色 + 3px `accent 12%` 微光；图标可转火（搜索） |
| 对话框输入 | 同描边规则；高 36–40；聚焦同上（禁止全量 accent 硬框） |
| 文本域（自定义 CSS 等） | 同输入框；等宽字体；最小高 120 |
| 清除键 | 自绘圆形 36；隐藏原生 `::-webkit-search-cancel-button` |

## 9. 分节与层级

- **页面结构**：顶栏（48 + 安全区，发丝线底）→ 内容（14 边距）→ 分节小标题 → 卡片 → `--space-6` → 下一节。
- **一页一个主标题**：顶栏标题 = 页面名；卡内分节标题不得重复页面名（待刷：外观/图片等页首节标题与页名相同，刷成删除或改「偏好」类词）。
- **页面层级**：家 → 文档（子页）→ AI/设置（推入页），返回遵循导航栈：AI ← 回文档，文档 ← 回家；设置子页 ← 回列表。
- **Sheet 层级**：行 ⋯ / 文档 ⋯ / 库切换 = 底部面板（`--z-sheet` = 500）；Toast 的 `--z-toast` = 300 在 sheet 之下——sheet 打开期间 Toast 会被遮（统一刷 H 项处理）。

## 10. 浮层

| 种 | 定式 |
| --- | --- |
| Sheet | 纸色卡 22 圆角 + grab 手柄 + 行（见 §7）+ 独立「取消」胶囊；遮罩 `--ui-overlay`；点遮罩关闭 |
| 对话框 | 271 宽 ∈ [min(352, vw−32)]；14 圆角；标题 17/600 居中；说明 13；按钮 48 行 + 发丝线；遮罩同上 |
| Toast | 居中胶囊：fit-content、最大 100vw−40、内距 10/20、13–15 字、`--z-toast`；位在键盘/格式条之上 |
| 菜单（ContextMenu 手机形态） | 一律落到 Sheet，不出现桌面浮层菜单；行数 >8 时 sheet 内滚动 |

## 11. 动效

只动 opacity/transform；时长取 `--dur-fast/base/slow`（120/200/320），不使用裸毫秒；关键帧集中在 `motion-tokens` 白名单。Sheet 进/出用 `motion-*` 既有动作；设置子页右滑 160ms（`settings-phone-push`，已注册）。

## 12. 禁止项（审查时会打回）

1. 组件里写颜色字面量 / 字号字面量（除已裁的空态 20px、裁决 15 的 12px 例外）。
2. `border: … solid color-mix(…)` 简写（WebView 114 整条丢弃 → 墨框）；一律 `border-color` 长写或纯 token。
3. 全宽 `border-top` 分行；必须内缩发丝线。
4. 把窄控件（开关）挤到第二排；带说明的行把控件塞进文字旁挤窄列。
5. 火色用于装饰、次级强调、普通可点文字（可点文字走 `--ui-accent-text`）。
6. 在手机上加桌面形态的菜单/页签条/分屏；新增入口先问「已有落点吗」。
7. 阴影用于静态内容；阴影只给浮层、FAB、Toast、对话框。
