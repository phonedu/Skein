# 插件兼容性（2026-11-22 核实）

> 结论：**Textus 插件在 Skein 上能用**。插件 API 与宿主未改；限制在视觉层，不在加载/权限层。
> 关联：[Textus 主题策略](../specs/Textus-主题策略.md) · [插件 API 要点](插件API要点.md)

## 1. 核实结果

| 项             | 结果                                                                       |
| -------------- | -------------------------------------------------------------------------- |
| 官方目录       | `C:\Project\textus-plugins`：`plugins/` 下 **60 个**插件                   |
| 版本门槛       | 60 个的 `engines.textus` 最高 `>=1.4.3`；本分支 `1.4.6-rc.3`，**全部通过** |
| API            | 仍为 API 1.9（Textus 1.4.6）；`textus.d.ts` 与宿主代码未分叉               |
| 插件子系统测试 | `npx vitest run src/plugins`：**75 文件 / 297 测试通过**                   |
| 应用内已有插件 | 应用数据里已有 `skein.collect`（本地插件，非官方目录）                     |

## 2. 怎么用

- **设置 → 扩展 → 插件**：
  - **Get more**：从官方目录/联网目录安装；
  - **More (…) → Load a plugin folder…**：加载本地插件文件夹（开发模式）；
  - **More (…) → Open Scripts Folder**：放单文件脚本（`==TextusScript==` 头）。
- 官方插件目录在 `C:\Project\textus-plugins`；e2e 插件流程需要这个检出（或 `TEXTUS_PLUGINS_DIR`）。
- 桌面/平板的插件列表进右页边，webview/流程页整页页签；手机全屏，Back 回上一页。

## 3. 视觉边界

- **用 Textus 控件/页面/列表的插件**：自动跟随当前 Skein 皮肤（Slate）与新的行/卡片 token，视觉一致；
- **自带 webview HTML、硬编码颜色的插件**：功能正常，但不会自动变成 Slate 玻璃皮肤；需要逐插件抽查，必要时给插件自己的页面加主题变量；
- **desktop-only 插件**（如 CLI agent 类）：不会在 iOS/手机上出现，这是 `platforms` 门控，不是 fork 损坏；
- **`appearance.setColors`**：可以改颜色，但与“皮肤锁定”冲突；阶段 1 定边界（建议只作用于插件自己的表面，不改全局 chrome）。

## 4. 建议的下一步

不需要为了“能不能用”改宿主。要做的是**抽 3–5 个代表性官方插件做一轮烟测**：

- 列表型（Tasks / Backlinks）；
- 页面/webview 型（PDF Viewer / Canvas）；
- 编辑器型（Vim / 代码块）；
- AI/CLI 型（按平台门控）。

烟测记录功能、权限、桌面/手机可见性、视觉是否跟随皮肤；发现硬编码颜色再逐个处理，不做全量插件 UI 适配。
