## 二、全局壳

- **壳网格**：行 = 窗栏 + 内容；列 = 活动轨道（48px）｜侧栏｜主面板。`src/app/App.tsx` + `src/app/frame/app-shell.css`；`data-tabs` / `data-sidebar` 属性驱动布局变体。
- **窗栏 WindowBar**（`src/app/frame/WindowBar.tsx`）：macOS 红绿灯嵌位、菜单栏或 ☰、侧栏开关、标题（未存点 + 只读锁）、插件状态项、Agent 钮 + Textus AI 钮、窗口控制钮；窄窗折叠走 `useFitSteps`。仅 `appDrawsWindowFrame` 时绘制。
- **活动轨道 ActivityRail**（48px）：侧栏页签图标（文件 / 大纲 / 搜索 / 插件，插件页签在下段，可拖拽排序 / 固定 / 隐藏）；更新徽章；底部设置齿轮。宿主原样（裁决 29 删掉了 C 组加的首组三视图钮与双导航重叠）。
- **侧栏 Sidebar**：标题 + 当前页签面板 + 拖拽把手，presence 动画，关闭中 inert。`src/app/frame/Sidebar.tsx`。
- **启动分层**：启动层只进壳 / 轨道 / 窗栏 / DocumentIslands / 页签注册；其余走 `src/lazy/`（ai-tab、outline、search-panel、plugins-panel、settings-features〔热〕、phone-parts…），`startWarming()` 首帧后预热。
- **窗口种类**（`src/main.tsx`）：一个 bundle，`?view=` 分 main / chat（独立聊天窗）/ floating（插件窗）/ background（无头插件宿主）。
- **浮层槽位**（挂 App.tsx）：SettingsLayer、ClosePrompt、AppDialogHost、ReportProblem、QuickPick、PluginForm、FloatingViews、NoticeHost、ZenExit、角落 toast 堆、Onboarding。
