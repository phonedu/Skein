## 二、全局壳

- **壳网格**：行 = 窗栏 + 内容；列 = 活动轨道（48px）｜侧栏｜主面板。`src/app/App.tsx` + `src/app/frame/app-shell.css`；`data-tabs` / `data-sidebar` 属性驱动布局变体。
- **窗栏 WindowBar**（`src/app/frame/WindowBar.tsx`）：macOS 红绿灯嵌位、菜单栏或 ☰、侧栏开关、标题（未存点 + 只读锁）、插件状态项、Agent 钮 + Textus AI 钮、窗口控制钮；窄窗折叠走 `useFitSteps`。仅 `appDrawsWindowFrame` 时绘制。
- **活动轨道 ActivityRail**（48px）：首组 = 今天 / 笔记 / 资产；分隔线；侧栏页签图标（拖拽排序 / 固定 / 隐藏）；更新徽章；底部设置齿轮。
- **侧栏 Sidebar**：标题 + 当前页签面板 + 拖拽把手，presence 动画，关闭中 inert。`src/app/frame/Sidebar.tsx`。
- **启动分层**：启动层只进壳 / 轨道 / 窗栏 / TodayPage / AssetsPage / DocumentIslands / 页签注册；其余走 `src/lazy/`（ai-tab、outline、search-panel、plugins-panel、settings-features〔热〕、phone-parts…），`startWarming()` 首帧后预热。
- **窗口种类**（`src/main.tsx`）：一个 bundle，`?view=` 分 main / chat（独立聊天窗）/ floating（插件窗）/ background（无头插件宿主）。
- **浮层槽位**（挂 App.tsx）：SettingsLayer、ClosePrompt、AppDialogHost、ReportProblem、QuickPick、PluginForm、FloatingViews、NoticeHost、ZenExit、角落 toast 堆、Onboarding。

## 三、逐屏

### 今天 ui-d-today —— ◐ v3 队列列落地（2026-11-17）

- **现有**：左队列列（页题「今天 · N」计数徽章；筛选框；进行中 / 该用的资产 / 待确认三组——**徽章硬编码 0 + 空态**；最近笔记组 = 真实数据 `readRecents()`，行 = 图标 + 名称 + meta + chevron，点击开文件并跳回笔记视图）；右主区 = 空态开始卡（「从左侧选择一件事开始」+ 去笔记钮）。
- **实现**：`src/features/today/TodayPage.tsx` + `today.css` + 测试；无 store，本地 useState。
- **交互位置**：轨道首钮（aria-label「今天」）；主面板独立占满，侧栏自动收起。
- **注**：三固定分组是 D1 聚合数据（任务 / 资产 / 确认）的落点；右区「选中内容有地方可去」随工作区 pass。

### 笔记 ui-d-notes —— ☑ 应用核心（完整）

- **现有**：文档页签（拖排序 / 拖出分离窗口 / 预览页签 / 右键菜单 / 未存关窗提示）；分栏（SplitDivider 拖放）；**单岛平铺**（Zen 或单栏时平铺，裁决 12，`40590519`）；StartPage（无文档时新建 / 打开）；FormatBar 选中工具条；AI 改动标记；Zen 模式；只读锁；引导教程。
- **侧栏页签**：文件（FileTree + 最近行）、大纲（lazy）、搜索（lazy）、插件（桌面 only，lazy）；插件可再加页签。
- **实现**：主面板 = `src/app/islands/DocumentIslands.tsx` → `DocumentViews.tsx`（挂编辑器）；岛 / 分栏机制 `src/engine/layout/`；页签引擎 `src/app/tabs/`；文档态 `useWindowDocuments` / `useWindowWiring`。
- **交互位置**：轨道第二钮；任意侧栏页签也会把视图拉回笔记。

### 资产 ui-d-assets —— ☐ 空壳

- **现有**：仅空态引导句（`assetsEmpty`）。无列表、无触发轴、无边界三件套。
- **实现**：`src/features/assets/AssetsPage.tsx`（16 行）+ `assets-page.css` + 测试。
- **交互位置**：轨道第三钮；主面板独立。

### 收集 ui-d-collect / 确认中心 ui-d-confirm —— ☐ 未实现

### Agent / Textus AI ui-d-agent —— ☑ 以聊天形态完整（时间线屏未建）

- **入口**：窗栏 Textus AI 钮 + AgentButtons（右键可暂停 / 关闭）；选中文本「Ask AI」；快捷键。
- **桌面**：会话 = 页面页签（`AppPage "ai"` → `AiTab`），默认开在右侧岛（`useAiTabs` / `AgentTabs`）；可分离成独立 OS 窗口（`ChatWindowRoot`，`?view=chat`）。
- **iOS**：停靠面板（`src/ai/chat/panel/agent-panel.tsx`，宽 330–792 可拖；Chat / Memory 两页签）。
- **富内容**：工具活动、引用、生成图、proposal / 文件变更卡、追问 chips、技能 / 主题 / 插件回复 chips（`src/ai/chat/`）。
- **门控**：`aiFeatures()`（总开关 textusAi）；`hasTextusAi`（中国大陆 iOS 关）。
- **注**：画板的「时间线」（每次调用一张卡片）未单独建——落点 C6，复用现有 AI 容器。

### 设置 ui-d-settings —— ☑ 完整（浮层已落地）

- **入口**：轨道底部齿轮 / `⌘,` / 应用菜单；深链可直达页 / 行（侧栏搜索、插件卡）。

## 四、手机与平板门控

- 手机布局 = `isMobileApp && ≤760px`（`src/platform/phone-layout.ts`）；桌面永不触发；平板 / 折叠态 = 桌面布局。
- 手机行为：单岛；轨道 + 侧栏从左推入（`usePushedSidebar`）；键盘协同（`src/mobile/keyboard.ts` + `useAgentDock`）；手机 composer / 格式条；样式 `src/mobile/styles/`。
- 能力门控集中在 `src/platform/capabilities.ts`（菜单、跨窗拖页签、PDF 导出、pandoc、废纸篓、CLI、更新器、触感、AI 可用性）。
