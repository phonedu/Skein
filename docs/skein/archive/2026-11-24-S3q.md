# S3q — 七牛 Kodo 原生传输专项（2026-11-24 完成）

> 工作线：S · 验收：上传凭证 + insertOnly transport；引擎 / 设置接线；真桶首次 / 改 / 删 / 冲突。

## 任务六行

- **problem**：七牛 Kodo 的 S3 兼容层接受第二次 If-None-Match 创建，内置同步的锁与 probe 判 unsafeServer，七牛用户无法安全使用内置同步。
- **expected**：七牛 Kodo 用户在设置里选原生模式后，首次/修改/删除/冲突都能同步；创建（锁）只成功一次；其它 S3 服务行为不变。
- **standard**：Kodo 创建走上传凭证 + insertOnly，第一次成功、第二次同 key 返回已存在（不同字节）；token/region/multipart 单测；真桶 probe 与引擎首次/改/删/冲突通过；设置页可选并在 10 个语言包有文案；npm run check:quick 与 cargo 测试通过。
- **not**：不重写插件 Cloud Sync 的 transport；不做七牛原生 GET/DELETE/列举（读写删继续走 S3 endpoint）；不改协议、不做自动同步；不测其它服务商或境外区域。
- **scope**：同步线（S 组）：textus-sync 的 S3Store + 设置页；桌面，真桶网络验证。
- **evidence**：cargo test -p textus-sync（token/up-host/multipart 单测）；cargo test -p textus-sync --test kodo_live -- --ignored（真桶首次/改/删/冲突）；vitest SyncPage；npm run check:quick。
