# S10 — 补齐同步重试、错误提示与 Kodo 防御缺口（2026-11-25 完成）

> 工作线：S · 验收：WebDAV/LAN Hub 复用 S3 的有界重试与 Retry-After；MOVE 与锁 DELETE 不在不确定后重发；rateLimited/quota/permission 有本地化提示；Bitiful 地址可识别；标准 S3 412 重发有测试；Kodo 区域必填在 UI 生效、key 校验与 token deadline 有测试；Rust/TS 区域表漂移有测试；全量检查通过。

## 任务六行

- **problem**：S9 只硬化了 S3/Kodo；WebDAV 与局域网 Hub 仍单次请求，429/503/502/504 直接失败。错误 UI 对 rateLimited/quotaError/permissionError 显示原始代码；Bitiful 要手填 region；标准 S3 的 412 重发只有代码没有测试；Kodo 空区域仍可点保存，key 未再校验，token deadline 与两处区域表缺测试。
- **expected**：WebDAV/Hub 与 S3 共享同一套重试语义，但 MOVE 与锁 DELETE 在无回答/网关后不重发；同步错误有可读文案；Bitiful 地址自动带出 cn-east-1/path-style；Kodo 未选区域不能保存；补 412 lost-reply、token deadline、区域表一致性测试。
- **standard**：不改协议；复用现有 transport 与错误码；重试最多 4 次、退避、尊重 Retry-After（>60s 报 rateLimited）；锁的 DELETE 与 MOVE 不可盲目重发；用户可见字符串补十语言；测试放最低层。
- **not**：不重写 transport；不做签名 head/块自愈等 S5 全量硬化；不新增 provider 协议；不改同步页信息架构（留给另一个界面任务）。
- **scope**：textus-sync retry/s3/webdav、settings 同步表单与错误文案、i18n、Bitiful 检测、kodo_live/s3 本地测试、区域表测试。
- **evidence**：cargo 单测（WebDAV 重试、MOVE/锁 DELETE、412/614）、Bitiful 真桶 s3_live、vitest 同步页/模型、npm run verify、docs:wrap。

## 证据

2026-11-25：S3/WebDAV/Hub 共用 4 次有界重试、退避、Retry-After（>60s 报 rateLimited），WebDAV MOVE 与锁 DELETE 不重发；rateLimited/quota/permission 三种错误补十语言文案；Bitiful 地址识别 cn-east-1/path-style；Kodo 空区域禁用保存、key 加 relative_path、token deadline 测试；S3 412/614 lost-reply、WebDAV 重试/不重发、Rust/TS 区域表一致性测试。Bitiful s3_live 1/1、Kodo live 4/4、Hub 17、textus-sync 68、全量 vitest 5254 通过（--maxWorkers=4）；typecheck/lint/prettier 通过。默认 npm run verify 在并行高峰有 SplitView 2 项 flaky，单跑通过。
