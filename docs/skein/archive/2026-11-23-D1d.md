## 验收发现（不在本任务修，留给 D1 线裁决）

- **A：快速收集不进资产闭环。** 记一句的 `skein.collect.capture` → `putNote` 写 `<vault>/inbox/<id>.md`（host.js `notePath`），资产库读 `asset-library/**/*.md`（`loadRecords`）。收下的一条能保存、能出现在 Today，但不在资产列表、确认流或检索里。第 3 条字面满足；闭环口径需要一次裁决（收下写 `asset-library/inbox/`，或列表兼读 `<vault>/inbox/`）。
- **B：阻塞原因的留档范围。** 原因存于待确认请求并在确认中心展示，确认后审计只存 request id，卡片不落 `blocked_reason` 字段。第 4 条字面满足；确认后是否留档待裁决。
- **C：Playwright 手机库 fixture 缺口。** 浏览器 harness 里手机壳的选文件夹流程不走 dev shim（`__devPickFolder` 未被手机壳路径消费），320px 的库走查只能上模拟器做。即 B5 已记录的 fork 壳 e2e 缺口之一。
