# D1t — Agent 时间线：工具调用卡片（2026-11-23 完成）

> 工作线：D1 · 验收：聊天里每次资产工具调用一张卡：工具名、参数摘要、结果、确认状态；确认状态接 D1b 队列；桌面 + 手机。未改动确认流本身。

## 任务六行

- **problem**：D1c 的七个工具调用在聊天里只有一行文字，看不到参数、结果和是否待确认，时间线无法回看。
- **expected**：每次工具调用一张卡，显示工具名、参数摘要、结果和确认状态；待确认项能从卡片进确认中心；其余工具的现有显示不变。
- **standard**：chat 单测覆盖 call/result 配对、结果摘要与待确认徽标；桌面 + 手机 built app 走查通过；不改 D1c 工具契约与 D1b 队列。
- **not**：不改七个工具的输入输出；不新建独立时间线页面；不让宿主直接读写插件的 project storage；不动同步。
- **scope**：宿主聊天 UI（Agent 面板）；桌面 + 手机。
- **evidence**：chat 单测；桌面/真机 built app 走查；必要时插件 result 补状态字段。

## 实现

- `src/ai/chat/asset-calls.ts`：`ASSET_TOOLS` 七工具集合；`assetCallsOf` 按 `call_id` 配对调用与结果（流式时结果为 null）；`assetParamsSummary` 各工具参数摘要（query/id/stage/title/补丁字段/id→target）；`assetResultOf` 解析插件信封 `{ok, data|error}` 成结构化摘要（count/id/useCount/pending/error），非信封输出返回 null（老对话回退普通行）。
- `AssetToolCard.tsx/.css`：卡 = 工具名 + 参数（截断）+ 结果行（条数 plural / 卡片 id / 使用累计 / 失败红字）；`request_confirm` 与 `propose_patch` 带**待确认**徽标，点击 `emitToThisWindow("menu-plugin-command", "skein.collect.confirm")` 打开确认中心——队列是真相，徽标只是入口。
- 接线：`chat-transcript.ts`（`assetCalls` map + `itemOf` 的 asset 卡/结果隐藏）、`ChatItem.tsx`、`chat-labels.ts`、`chat-messages-types.ts`；十语言 13 条新串。
- 未动：七个工具输入输出、D1b 队列、确认流本身、其余工具的行渲染。
