# PH14 — 手机手势按 iOS 橡皮筋手感：非线性位移 + 阻尼 + 回弹（2026-11-26 完成）

> 工作线：UI · 验收：横滑松手按速度交接的弹簧落页（不是固定 320ms）；Sheet 下拉按速度/距离关闭并带初速度回弹；分段滑块跟手且与内容同步收尾。观察项结案：Sheet 进入 450ms（弹簧缓动约 313ms 视觉静止）不缩；PhonePager 旧注释已清理；扩展页分段横滑归 PH15，合并带入的 e2e 红归 PH16。

## 任务六行

- **problem**：当前手机横滑只用线性阻尼（PAGER_RESIST 0.25）+ CSS 过渡松手回弹，手感生硬。iOS 的橡皮筋是“非线性位移 + 阻尼 + 回弹”：手指移动与控件位移不成正比，越拉越难、松手弹回；用户举例卡片下拉展开用渐近式 maxExpansion*(1-exp(normalized*0.65))。
- **expected**：手机手势按 iOS 手感：位移随手指非线性增长并渐近饱和，越界有阻尼，松手按位置/速度回弹；先覆盖今天/文件横滑，再看库面板与卡片下拉；不做线性系数、固定时长的死硬动效。已做：指数越界阻尼（5446bfb8）、Sheet 抓手下拉与从松手位置关闭（f9f5ff77/02d17b8a）；还差：横滑松手速度交接、Sheet 下拉的速度判定、分段滑块跟手。
- **standard**：位移曲线单调、连续、有渐近上界；松手回弹无跳变；松手把手指速度交给弹簧（横滑用 pagerVelocity 作初速度，Sheet 用下拉速度）；分段滑块的 --segment-at 随拖动进度走，落页与内容同一弹簧；参数集中可调（阻尼系数 k、上界、回弹弹簧）；reduced motion 收敛；单测曲线 + Android WebView 实滑/录屏；只借交互模型，不照搬 Apple 私有代码。
- **not**：本轮不做：Android WebView 无原生 ScrollView 橡皮筋（是否自研另议）；Sheet 进入 450ms 实测总时长 450ms、视觉约 313ms 已静止，不缩；PhonePager 旧注释已随本轮清掉；扩展页分段横滑归 PH15、合并带入的 e2e 对不齐归 PH16；不整页重写、不引第三方动效库、不改桌面/平板、不逐帧手调系数。
- **scope**：src/phone（usePagerSwipe/pager-model）、engine/motion（新增弹簧积分器，纯逻辑+单测）、PhoneViewSeg/Segmented 的分数滑块、engine/controls/Sheet 的下拉速度；手机布局；先横滑，后卡片下拉。
- **evidence**：弹簧积分器单测（位移/阻力/回弹/初速度）；e2e 或分帧截图断言松手后的运动；Android 模拟器实滑/录屏。

## 证据

弹簧积分器 engine/motion/spring.ts 8 项、swipeVelocity 5 项单测；pager e2e 5 项（逐帧断言滑块跟手、松手速度交接、收尾清 inline/变量）、sheet e2e 2 项（60px 快拉关闭/40px 慢拉回弹）；vitest 668 文件 5569 项全绿（--maxWorkers=4）；npm run build 通过；Sheet 进入实测：--dur-sheet 450ms 弹簧缓动，约 313ms 视觉已静止，不缩；扩展页确有分段（ExtensionsPage.tsx:61 Segmented），横滑归 PH15；合并带入的 12 条 phone-touch/fork-shell e2e 在 HEAD 上同样红，与 PH14 无关，归 PH16。
