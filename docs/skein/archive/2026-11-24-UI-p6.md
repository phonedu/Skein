# UI-p6 — 手机库页同步提示改为瞬时提示（2026-11-24 完成）

> 工作线：UI · 验收：库页/今天不再有常驻同步框；新同步完成或失败时出现会自动消失的提示；不遮挡今天/文件与列表；同步设置仍可进入；手机截图验收。

## 任务六行

- **problem**：手机库页在 Today/Files 下面常驻一个带边框的同步框，挤占列表并和分段控件重叠；其他应用用图标或完成即消失的提示。
- **expected**：删掉常驻框；检测到新的同步结果时用现有 notice 显示一次，成功后自动消失；历史结果不在每次打开时重复；失败用错误色提示。
- **standard**：复用 showNotice；只在 last.at 变新或最近完成时提示；不新增协议/状态；手机 360 宽截图。
- **not**：不新增常驻同步面板；不跳设置；不改同步状态数据结构；不做多端通知中心。
- **scope**：PhoneSyncStatus、PhoneHome/PhoneToday 的挂载位置、PhoneHome.css 清理、相关 vitest。
- **evidence**：手机库页无同步框截图；同步后提示出现并消失；PhoneSyncStatus 单测。

## 证据

The phone library/Today no longer mounts a bordered sync row; a fresh result uses showNotice and leaves after a few seconds. PhoneSyncStatus 2 tests, typecheck, eslint and the real-phone pairing run pass.
