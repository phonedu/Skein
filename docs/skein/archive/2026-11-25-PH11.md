# PH11 — 手机今天与文件左右滑动切换（2026-11-25 完成）

> 工作线：UI · 验收：手机今天/库页中部横滑跟手，按距离/速度落页；纵向手势、行拖拽与点击不误触；胶囊点按不变；无横向溢出；pager 单测与 Android UA e2e 通过。

## 任务六行

- **problem**：手机今天页与文件库页各自渲染，只能点 Today|Files 胶囊切换；手指在页面中部左右滑没有任何反应，与成熟移动端两页横滑的习惯不符。
- **expected**：在手机今天/库页中部左右滑，页面跟手横移，松手落在今天或文件页；胶囊点按、记一句、⋯、搜索、纵向滚动、行拖拽与点击的行为都不变，滑动后不误开文件。
- **standard**：横滑跟手无跳变；距离或速度决定落页；纵向手势不切页；滑动后不触发被滑过控件的点击；今天/文件胶囊选中态与所落页一致；无横向溢出；动效只用 --dur-*/--ease-*，reduced motion 收敛；pager 单测与 e2e（Android UA + CDP 触摸）通过。
- **not**：不重排今天/库页顶栏与内容；不改桌面与平板导航；不加文档页与库页之间的横滑；不改 Android 系统返回键与左缘手势；视觉未认可前不提交（纪律 §11）。
- **scope**：手机布局（<600）今天/文件两页；src/phone、src/app/App.tsx、e2e；桌面与平板不受影响。
- **evidence**：npx vitest run src/phone/pager-model.test.ts src/phone/PhonePager.test.tsx；npx playwright test e2e/phone-pager.spec.ts；npm run check:quick -- <改动文件>；截图/录屏。
