## 每张一句话

- **M0**：导航栏、文件栏、编辑栏、AI 栏不再各占一根柱子，而是合成文库、工作面、成果架三个角色区。
- **M1**：桌面只有三个区，AI 以贴着段落的蓝色页边卡出现，成果架保存带来源和验证状态的资产。
- **M2**：选中一句后，📌 钉住把蓝色建议变成红色承诺，并同时落入页边与成果架。
- **M3**：手机先保护全文阅读，页边线索压缩成段落尾标记，底栏只保留四个目的地。
- **M4a**：点段落标记后，底部 sheet 只展示 Agent 建议和接受 / 驳回 / 钉住动作。
- **M4b**：钉住后选择 sheet 已关闭，底部显示已钉入成果架，并在成果架 sheet 中展示带来源和验证记录的新卡。
- **M5**：核心宣言是“三栏，不是四根柱子”，唯一跨区的动词是“钉住”。

## 关键取舍

1. **三区而非四栏**：文库吸收导航与文件；工作面吸收编辑与页边；成果架承担原本被误做成 AI 栏或资产列表的结果。
2. **AI 不单独占位**：Agent 建议、待确认判断、资产候选都锚定段落，蓝色代表仍在上下文中。
3. **资产不是列表**：成果架卡片保留状态、来源、验证记录，红色钉子表示用户已经作出承诺。
4. **手机不缩小桌面**：手机是全屏文档 + 段落标记 + 底部 sheet，成果架作为工作台内的 sheet / 段落，不增加第五个底栏入口。
5. **视觉识别系统**：蓝 `#2383E2` 表示上下文，红 `#EB5757` 表示承诺，灰发丝线表示来源；正文使用 serif 以强调阅读与判断。
