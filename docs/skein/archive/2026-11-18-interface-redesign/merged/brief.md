## 用户裁决

- 合并 A（页边）与 B（工作台）。

- 新结构必须把四根柱子合成 **三个区**，且 **AI 不再是栏、资产不再只是列表**。

## 核心叙事

```text
旧： [导航栏] [文件栏] [编辑栏] [AI 栏] = 4 根柱子
新： [文库（导航+文件合一）] [工作面（文档+页边）] [成果架（资产）] = 3 个区
```

- **导航栏 + 文件栏 → 文库**：一列。顶部横向分段 今天 / 笔记 / 收集 / 资产；下面接当前库的文件 / 最近。不是轨道 + 文件树两列。
- **编辑栏 → 工作面**：文档 + 右侧页边槽。页边不是独立栏，是文档的边。
- **AI 栏 → 页边**：Agent 的批改、待确认判断、资产候选贴着段落出现；不是聊天栏。
- **资产列表 → 成果架**：判断 / 资产卡（状态、来源、验证记录）；可收起，是第三栏。
- **钉住（📌）是桥**：选中一句 → 钉住 → 选择判断 / 资产 / 稍后 → 卡进入页边并落到成果架，来源线保留。

## 颜色语义（本次的识别系统）

- **蓝 `#2383E2`**：上下文 / Agent / 页边线索（还留在文档里）。
- **红 `#EB5757`**（可略深）：用户的承诺 / 已钉住 / 进入成果架（离开文档，成为资产）。
- **灰发丝线**：来源线 / 验证记录。
- 蓝 → 红是一次「决定」：Agent 提议是蓝的；你点钉住 / 采纳后，卡上的钉变红，进入成果架。
- 这是产品的核心动作，不要做成装饰。

## 桌面版面（1440×900）

- **顶栏**：库名 + 当前文档 + 搜索 / Ctrl K + 成果架开关。不要第二排导航。
- **左：文库**（可收起，约 280px）：顶部横向分段 今天 / 笔记 / 收集 / 资产；下接文件 / 最近列表。不是轨道 + 文件树两列。
- **中：工作面**（flex）：文档 + 右侧页边槽（约 220–240px）。页边卡按段落编号 `02 / 05` 锚定，细连线；页边是文档的边，不是第四列。
- **右：成果架**（可收起，约 280px）：判断 / 资产卡；卡上有状态（待验证 / 已验证 / 可复用）、来源、验证记录；收起时只留一条窄边 + 数量。
- **不要常驻 AI 栏**：Agent 只在页边出现。
- **不要常驻文件树 + 轨道**：文库是一列。

## 手机（360×800）

- 全屏文档；段落尾 `02 / 05` 蓝色页边标记；点标记 → 底部 sheet 显示对应卡（接受 / 驳回 / 钉住）。
- 钉住：选中文字 → 底部浮动 📌；选择 判断 / 资产 / 稍后；卡进入页边并落到成果架。
- 底部导航：**工作台 / 笔记 / 收集 / 资产**；「今天」从文库 / 菜单进；成果架是工作台内的一个 sheet / 段，不占底部第五格。
- 不要桌面缩小；不要四根柱子。
