## 这是什么

旧界面被用户判为「四根柱子」：导航栏、文件栏、编辑栏、AI 栏各占一列。
这版合并概念把它们收成**三个区**：

```text
旧： [导航栏] [文件栏] [编辑栏] [AI 栏] = 4 根柱子
新： [文库（导航+文件合一）] [工作面（文档+浮动页边）] [成果架（判断/资产）] = 3 个区
```

- **文库**：顶部今天 / 笔记 / 收集 / 资产，下面直接是当前库文件；不再有轨道 + 文件树两列。
- **工作面**：文档 + 浮在右侧留白里的页边卡；Agent 不再是独立栏，批改/判断/资产候选贴着段落出现。
- **成果架**：判断 / 资产卡，带状态、来源、验证记录；可收起。
- **钉住（📌）**：选中一句 → 钉住 → 判断 / 资产 / 稍后；蓝色（仍在上下文）变成红色（已承诺），卡同时进入页边与成果架，来源线保留。
