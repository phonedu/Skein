# PH12 — 库切换面板（桌面下拉 / 手机底部）（2026-11-25 完成）

> 工作线：UI · 验收：点库名出面板：当前库带勾、最近库可切换、添加库进选择器、每行垃圾桶只移除列表条目；桌面下拉、手机底部；打开库写入最近列表（含 SAF URL）；文件/项目设置/同步绑定/草稿/页签不变；桌面与手机 e2e、Rust 单测通过。

## 任务六行

- **problem**：手机端只能打开一个库，已用过的库无法回切；手机打开库不写最近列表。桌面库名按钮带 chevron 却直接弹文件夹选择器，没有最近库与移除入口（File > Open Recent 里才有一份只读列表）。
- **expected**：点库名出面板：当前库带勾，已用过的库点一下即切换；底部“添加库…”进文件夹选择器；每行垃圾桶只从列表移除该库，不删文件。桌面用按钮下方下拉面板，手机用底部面板；桌面 File > Open Recent 与面板同步。
- **standard**：手机打开库写入 recentFolders（含 content:// SAF 地址，重启后可再次打开）；移除只删列表条目，文件、项目设置、同步绑定、草稿、页签都不变；当前打开的库不显示垃圾桶；十语言字符串；只用 token；桌面/手机 e2e 与 Rust recents 单测通过，bindings 无漂移。
- **not**：不删文件/文件夹/项目设置/同步绑定；不做多库同时挂载或多窗口库栏；不改 File > Open Recent 的原生形态；不加命令面板“切换库”入口。
- **scope**：src-tauri recents 命令与注册、bindings、src/platform 最近库 IPC、Sidebar、PhoneToday/PhoneHome、i18n、e2e；桌面 + Android/iOS 手机布局。
- **evidence**：cargo test recents + npm run bindings；vitest vault-model；playwright 桌面与手机用例（切换/移除/不删文件）；桌面 1280 与手机 390 截图。
