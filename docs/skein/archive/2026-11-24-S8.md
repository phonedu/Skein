# S8 — 局域网 Hub 发现与扫码补齐（2026-11-24 完成）

> 工作线：S · 验收：手机在同一 Wi-Fi 能发现桌面 Hub 或扫桌面二维码完成配对，不再手输地址和码；mDNS 与 UDP 广播混合、结果去重；发现/扫码失败可回退手输；不广播 token/code，不暴露公网；真机验收。

## 任务六行

- **problem**：S4 v1 只做了地址 + 6 位码手输；没有自动发现、二维码扫描和设备在线状态，和成熟局域网同步软件相比配对体验明显差。
- **expected**：桌面 Hub 同时用 mDNS 广播和 UDP 广播兜底；手机浏览/探测后列出附近 Hub 并预填地址；桌面显示一次性二维码，手机应用内扫码后直接配对；设备列表显示在线/离线与最后出现；手输保留。
- **standard**：混合发现 mDNS 优先、UDP 兜底，结果按地址+repo 去重；发现只暴露名称/地址/端口/repo；二维码一次性、仅私网；扫码与手输复用 hub_pair；字符串十语言；桌面与 Android 真机。
- **not**：不做公网中继、P2P、TLS、后台自动暴露；不改 /1 协议与同步引擎；不做手机展示二维码；iOS 无真机只做构建检查。
- **scope**：textus-discovery crate、textus-hub 广播、app 发现/二维码命令与 SyncHub UI、barcode scanner 插件、i18n、单测与真机验收。
- **evidence**：发现/二维码 payload 单测；桌面+华为同 Wi-Fi 无输入配对与首次同步；mDNS 关闭/被挡时 UDP 兜底；撤销与只读回归。

## 证据

Real Huawei OXF-AN10 on the same Wi-Fi completed pairing against the desktop Hub; phone shows the saved WebDAV connection and desktop lists it online. Hybrid discovery returned mdns+udp; QR payload decodes correctly; after the rear camera returned black frames the app's own camera view, jsQR decoder, camera switch and cancel were added and used. cargo tests, typecheck, eslint, docs checks pass.
