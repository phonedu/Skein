# 方向 D2 · 三栏桌子（在 D 的视觉上重排 IA）

保留 D 的视觉语言：暖纸、宋体、铅笔 / 墨 / 朱、页边批注、收尾 sheet 的仪式感。
只重排信息架构，解决 D 的两个问题：

1. 左上“笔记 / 库 / 复盘 / 设置”像应用页签，不好看，也不符合理论。
2. 三栏没有按每栏的用途排。

## 核心变化

- **删掉左上页签。** 窗口顶部只留：当前笔记标题 / 状态 chip / 待确认 / ⌘K。
- **三栏按用途分：**
  - 左 = 定位：今天 / 最近 / 当前交付；顶部可切换“今天 / 文件”两种视图。
  - 中 = 正文：唯一主舞台。
  - 右 = 页边：Agent / 资产 / 收尾；默认空，按状态和选择出现。
- **左栏的“今天 / 文件”是侧栏视图切换，不是应用页签。** 默认“今天”。切到“文件”显示真实 Markdown 文件夹树，当前笔记高亮；中间正文不变。
- **库 = 中央搜索结果视图**（⌘K / 搜索触发），不是左栏的第二个页，也不是一级页签；左栏保留。
- **复盘 = 低频入口**（左栏底部 / 命令），覆盖式，不常驻。
- **设置 = 菜单 / 齿轮**，不占一级。

## 四个状态的右栏

- 普通笔记：页边空，只写“选中一段，或按 ⌘K 叫 Agent”。
- 这一单：页边显示开工前该看的资产（先不适用，再适用）。
- 已交付：页边变成收尾 sheet，七行；铅笔 = Agent 起草，墨 = 人点过，朱 = 待确认。
- Agent 被叫：页边是铅笔提议，逐条留下 / 退回；没有聊天流。

## 左栏两种视图

### 今天（默认）

- 顶部：视图切换“今天 / 文件”；搜索框。
- 当前交付：标题 + 状态 chip + 预期；没有就写“还没有当前交付”。
- 最近：5–7 条笔记，带状态 chip（笔记 / 这一单 / 已交付）。
- 底部：待确认 3、复盘。

### 文件

- 顶部：同一个视图切换“今天 / 文件”；搜索框；新建按钮。
- 真实 Markdown 文件夹树：普通笔记 / `asset-library/`（inbox、tasks、judgments、assets）。
- 当前笔记高亮；文件树不是资产库导航，只是文件入口。
- 底部：待确认 3、复盘。

## 关键屏（至少画）

1. 桌面首屏（今天视图）：三栏 + 顶栏无页签 + 左栏切换 + 当前交付 / 最近 + 右栏空提示。
2. 桌面文件视图：同一篇笔记，左栏切到文件夹树，当前笔记高亮；中间正文不变。
3. 桌面收尾 sheet：右栏变收尾，七行；左栏保持今天。
4. 桌面库 / 搜索：中央变结果，左栏保持；顶部显示“库 / Esc 返回”。
5. 桌面 Agent 页边：选中文本，右栏 2–3 条铅笔提议。
6. 手机首屏：最近笔记 + 大捕获按钮；左栏是抽屉，抽屉顶部也有“今天 / 文件”。
7. 手机收尾 / 确认：底部 sheet，七行短确认。
8. 平板横屏：笔记 + 右栏；左栏可收成图标或抽屉。
9. 平板竖屏：单栏笔记 + 底部 sheet；不压三栏。

## 设计语言

沿用 D：暖纸、低铬、编辑器为主；Agent 像铅笔批注；收尾 sheet 是仪式；只用一个强调色（朱）给待确认 / 冲突。左栏切换要像侧栏里的一个小开关，不要像应用 tab bar。

## 不要做

- 不要恢复“笔记 / 库 / 复盘 / 设置”四个应用页签。
- 不要常驻聊天栏、资产库一级入口、任务看板、四时刻导航、指标仪表盘。
- 不要把文件树做成首页；它只是左栏的一个视图。
- 不要让右栏变成永久 tab；它是上下文页边。

## 输出

- 一个 HTML 片段：根 div + style + 内容；不要 doctype / html / head / body / script；无外部资源；中文标签。
- 文件名：`opencode-direction-d2-three-column.html`。
- 页面顶部写“方向 D2 · 三栏桌子”，并写一句“左栏定位/文件切换，不是应用页签”。
- 底部一行“不是入口 / 失败模式”。
