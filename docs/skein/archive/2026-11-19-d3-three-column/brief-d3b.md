# 方向 D3b · Agent 动作改成页边列表（D3 修正）

只改 Agent 交互，不动 D3 的其他布局和视觉。

## 问题

D3 里选中文本后，正文上方出现一条黑色浮条“问 / 改 / 提炼”：

1. 它是全场唯一的弹窗式控件，和页边的标题 / 列表语言不一致。
2. 文本在页面底部时，浮条会和系统选择工具栏重叠。

不要尝试把我们的动作合并进系统工具栏：macOS / Windows / Linux / Android 的选择菜单各不相同，接入是平台维护陷阱。

## 改法

### 桌面 / 平板

- **删除浮条。** 选中文本后，右栏直接变成“页边 · 对选中这段”。
- 右栏用标题 + 列表，和收尾 sheet / 库 / 资产同一种语言：
  - 标题：对选中这段
  - 副标题：2 句 · 已选中
  - 三行动作，每行是标题 + 一行说明：
    - 问 · 解释这段在说什么
    - 改 · 把这段改清楚
    - 提炼 · 提炼成一条判断
- 点一行后，右栏换成对应的铅笔提议（如“改 · 草稿”“提炼 · 草稿”），顶部保留“返回动作”或“再选一个”。
- 右栏一次只显示一件事。如果当时右栏是收尾 sheet，选中文本后先换成动作列表，并给一个“回收尾”的返回入口；不要叠两层。
- 系统选择工具栏不动；我们的动作永远在页边，不覆盖正文。

### 手机

- **不要自动弹浮条。** 选中文本时不出现任何浮层，系统选择工具栏正常。
- 笔记页底部有一个“Agent”按钮（或命令栏里的“问 Agent”）；点了才从底部升起 sheet。
- sheet 里用同样的标题 + 列表：对选中这段 → 问 / 改 / 提炼；点一行后换成提议。
- 长 diff 仍提示去平板或桌面。

## 输出

- 在 D3 基础上创建新文件 `opencode-direction-d3b-agent-list.html`，不要覆盖 D3。
- 保留 D3 的全局宽屏图、三栏、收尾、库、手机首页/抽屉、平板横竖屏。
- 只替换 Agent 那一屏（以及手机 Agent 的入口说明）。
- HTML 片段，无外部资源，中文标签；顶部写“方向 D3b · Agent 页边列表”；底部“不是入口 / 失败模式”。
