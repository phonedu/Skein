## 它解决的是什么

先前的 A/B/C 三版（案头 / 纸页 / 四刻）都把理论放到了第一屏：打开应用先建单、先选时刻、先看页脊，用户是在“管理系统”，不是在写东西。D 改成“笔记优先、Agent 内联、资产后置”，用户判“还行”，但指出五个问题：

1. 移动端把“今天”放进了抽屉上栏，不对；
2. 桌面不是真三栏，右栏条件出现，只有一个左栏的样子；
3. 没有一张全局图，左栏 / 正文 / 页边被拆开画；
4. 不够简洁；
5. 平板不像平板。

D3 的修正：

- **桌面真三栏**：壳满宽，左 280 / 中 1fr（纸页限宽 720）/ 右 360；右栏宽屏常驻，按状态变。
- **顶部不再有“笔记 / 库 / 复盘 / 设置”页签**；顶栏只留标题、一个状态 chip、待确认小点、⌘K。
- **左栏是“今天 / 文件”视图切换**，不是应用页签；文件视图是真实 Markdown 文件夹树，中间正文不动。
- **库是中央搜索结果**；复盘低频；设置进 ⋯ 菜单。
- **右栏一次只出现一件事**：空 / 资产 / 收尾 / Agent。
- **手机首页 = 今天**；抽屉只放文件 / 复盘 / 设置，没有“今天”tab。
- **平板**：横屏 4:3 两栏 + 右栏滑出；竖屏 3:4 单栏 + 底部 sheet；不再是缩小桌面。
- **Agent 动作不再用浮条**：选中文本 → 右栏“对选中这段”标题 + 列表（问 / 改 / 提炼）；手机用底部 sheet，不自动弹。D3b 修了这一点，但没有给用户看过，未验收。

## 用户明确保留的反馈（以后美化 / 调整前先读）

1. 理论是后台纪律，不是前台导航；不要把“四刻 / 页脊 / 单卡”做成一级。
2. 三栏按用途分：左定位、中写作、右上下文；不是按功能模块分。
3. “这一单”是笔记的状态，不是另一级对象。
4. 库是搜索 / 筛选视图，不是一级页；复盘低频；设置进菜单。
5. 左栏可切换“今天 / 文件”，这是视图切换，不是应用页签。
6. 左栏“今天”在手机上必须是首页，不是抽屉里的 tab。
7. Agent 不要浮条 / 弹窗；动作放页边，用标题 + 列表；不要试图合并系统选择工具栏。
8. 平板要像平板：横屏两栏 + 滑出，竖屏单栏 + 底部 sheet，触控 44px。
9. 大屏要真三栏：壳满宽，中栏纸页限宽 720；不要 1120 窄带。
10. 简洁：顶栏一行，右栏一次一件事，只用一个强调色。
