# 方向 D3 · 宽屏三栏（D2 修正）

保留 D 的暖纸 / 铅笔 / 朱，但这次先解决五个问题：

1. 桌面不是真三栏：壳被限在 1120px，左 148 / 右 300，右栏条件出现；大屏像窄带。
2. 没有一张全局图：左栏、正文、页边被拆开画；要一张宽屏完整界面。
3. 不简洁：卡片、标签、提示太多；要像纸和笔，不像仪表盘。
4. 移动端把“今天”放进了侧栏顶部；今天应该是手机首页本身，不是抽屉里的 tab。
5. 平板不像平板：不要缩小桌面；平板用两栏 + 抽屉 / 滑出面板，触控尺寸。

## 桌面：真三栏

- 窗口满宽，**不要沿用 D2 的 1120px max-width**；顶栏通栏。
- 左 280（可收 64）、中 `minmax(0,1fr)`、右 360（可收）。
- 中栏纸页 `max-width: 720px`，居中；多出的宽度是桌面留白，不要把正文拉长。
- 右栏宽屏常驻，内容随状态变；空态也要有一张安静的“页边”提示，不能空白。
- 三栏全高，1px 竖线；左 / 右 desk 面，中间纸页浮起。
- 断点：≥1360 `280|1fr|360`；1100–1360 `240|1fr|320`；900–1100 左收图标、右变浮层；<900 单栏。

## 第一张必须是全局宽屏图

- 第一张、最大：**1600×1000（代表 1920 宽屏）**，完整应用壳，左中右三栏都在，内容真实：
  - 左：今天 / 文件小开关、当前交付、最近 4–5 条；
  - 中：周四 · 把第二版交出去，正文，状态 chip；
  - 右：页边 · 资产（当前交付的开工前资产），不是空白。
- 图上不要写说明；说明放在图下一行。
- 这张图要让用户一眼看到“这就是三栏”，不是左栏 + 空白。

## 其他桌面状态（都用同一个完整壳，不要拆栏）

- 1440 默认：普通笔记，右栏安静提示（一张安静的页边提示，不是空）。
- 收尾 sheet：右栏变七行。
- 库：中央搜索结果，右栏选中项。
- Agent：右栏铅笔提议。
- 左栏文件视图：文件夹树，当前笔记高亮。

## 极简

- 顶栏只留：标题、一个状态 chip、待确认小点、⌘K。不要多个按钮。
- 左栏：当前交付用一条细线文本，不要大卡；最近列表每行最多一个状态词，不要两个 chip。
- 中栏：纸页，大留白；不要装饰。
- 右栏：一次只出现一件事（一个资产 / 一张收尾 / 一组提议），不要叠卡。
- 只用一个强调色（朱）给待确认 / 冲突；其余用墨 / 灰。
- 少用边框和阴影；用留白和字重分层。

## 手机

- 首页 = 最近 + 记一句；**不要“今天 / 文件”切换**。今天就是首页。
- ≡ 抽屉：只放文件 / 复盘 / 设置；不要“今天”tab。
- 笔记页：轻编辑 + 状态 chip + 待确认卡。
- 收尾：底部 sheet。

## 平板

- 画成真正的平板：横屏 4:3，竖屏 3:4，有摄像头 / 边框 / 手势条。
- 横屏：两栏——左侧抽屉 / 窄栏 + 笔记；右侧页边是**滑出面板**，不是常驻 360 桌面栏；触控 44px。
- 竖屏：单栏笔记 + 底部 sheet；顶部抽屉按钮。
- 不出现桌面三栏缩小版。

## 输出

- HTML 片段；根 div + style；无外部资源；中文；文件名 `opencode-direction-d3-global.html`。
- 顶部写“方向 D3 · 宽屏三栏”；底部一行“不是入口 / 失败模式”。
- 屏幕数量控制在 9 张以内；第一张必须是全局宽屏三栏图。
