# S6 迁移 / 双开 / 首连 dry-run 归档（2026-11-20）

> **状态：完成。** 插件用户可以先预览、导入连接与基线，再用内置同步；插件仍启用时页面会警告，手动同步前再确认；断开内置同步即回退。
> 设计依据：[同步方案 §10](../02-方案/同步方案.md)、[迁移评审 §5](../03-调研/同步评审/03-产品体验与迁移评审.md)。

## 1. 完成内容

| 层 | 落地 |
| --- | --- |
| 首连预览 | `textus-sync::preview` 只读三路扫描：上传/下载/远端删除/本地删除/冲突/移动/不变的数量与字节数，空扫描与批量删除标记；`sync_preview` 不取锁、不写 base/head；设置页「预览」与摘要、两条保护提示 |
| 插件导入 | 读 `config:<sha256(root)>`、`plugin_secrets.json` 的连接密钥、`encrypted-base:<hash>` 与 pin；root 按 canonical / plain / 斜杠候选匹配；导入成内置连接、绑定、每库密码、base 与 pin；失败回滚连接 |
| 双开检测 | `sync_status` 返回 `pluginConfigured`（该 root 仍有插件配置）与 `pluginRunning`（插件在 `plugins/state.json` 中启用）；两者都在时同步页显示危险提示与「打开插件」，手动同步前再确认；插件已停用时提示可以卸载 |
| 停用 / 卸载 | 文案明确顺序：先停插件对该库的同步 → 验证内置首次同步 → 再卸载；不自动停用插件、不自动改插件设置、不删插件数据 |
| 回退 | 「断开」删除内置 binding/base/last（连接仅在无其他库使用时删除）；插件配置、凭据、base 与云端对象不动。插件配置仍存在时页面常显回退说明；失败后可断开并重新启用插件，接受一次对账与少量冲突副本 |

## 2. 验收证据

- **built app + 真实插件夹具 + 缤纷云 S3**：用插件自身的 `Settings` / `RemoteStore` 生成真实 config、secret、base 与 pin，写入 portable app 的插件存储；内置导入后连接字段（endpoint/bucket/region/prefix/凭据/加密/路径式）与插件一致。
- **导入基线生效**：首次预览显示上传/下载/删除/冲突均为 0；同步显示“上传 0，下载 0，删除 0，冲突 0”。
- **增量仍走导入的连接**：编辑 `Notes/a.md` 后同步显示“上传 1”；远端 `head.json` 指向新哈希，对应块内容与本地文件逐字节一致。
- **built app 双开走查**：portable 构建 + 插件 kv/state 夹具：插件启用时同步页显示危险提示与回退说明，「立即同步」弹出“仍要同步”确认；把插件 state 改为停用后重开，提示变为“已停用，可卸载”；两者都不自动改插件。
- **测试**：`sync::plugin` 2 单测（含无密钥的配置检测）；SyncPage 11 页面测试（双开横幅、同步前确认、未配置时不警告、预览摘要、插件导入等）；十语 108 测试。
- **清理**：测试 prefix 的 6 个 S3 对象已删除；portable app 夹具、本机 WebDAV 服务、插件临时测试文件与导入凭据已移除。

## 3. 不在本片

- **自动同步**：内置目前只有手动同步；自动同步落地时必须在每次运行前重查双开状态，仍双开则跳过自动运行，手动同步保留确认。
- **插件 kv 备份**：导入不修改插件数据，未卸载时回退不需要备份；若用户提前卸载，按回滚说明重装并作为新设备加入。
- **冲突中心**：S6 只做首连冲突计数；冲突列表/对比/三选一仍归 S2 后续或独立项。
- **真机与第三方服务**：手机插件 ↔ 内置共用仓库归 S2-3/S3；第三方 WebDAV 归 S2-1。
