# PH6 — 插件平台：接受 android，iOS 插件在安卓仍可运行（2026-11-24 完成）

> 工作线：UI · 验收：manifest 列出 android 可安装/启用；仅列 ios 的插件在安卓仍运行；后台/agents 仍只许 desktop；Rust 与 TS 同一份平台表与共享用例

## 任务六行

- **problem**：安卓装 0.7.1 报『No platform android: desktop or ios』：permissions.json 的平台表只有 desktop/ios，Rust 校验与前端 parseManifest 都拒绝 android；runsHere 又把所有移动端当成 ios。
- **expected**：平台表含 android；Rust/TS 校验、错误文案与共享用例一致；安卓接受 android 与 ios，iOS 不接受仅 android；后台与 agents 仍拒绝手机平台。
- **standard**：沿用 permissions.json 单一来源（Rust include_str + 前端 import）；共享 manifest-cases.json 双端同判；改被镜像的两处并各自补测。
- **not**：不重打 0.7.1 插件包（其 manifest 已列 android）；不动权限种类；不改应用商店/签名。
- **scope**：src/plugins/store/{permissions.json,manifest.ts,manifest-cases.json,manifest.test.ts}、src-tauri/src/plugins/manifest.rs、src/plugins/plugin-platform.ts(+test)、docs/dev/textus-plugin.schema.json
- **evidence**：待真机

## 证据

2026-11-24 真机 Huawei OXF-AN10（debug 1.4.6 新构建）：Skein 收集 由 0.6.0 升到 0.7.1 并加载，记一句弹出收集面板（无空白页）；plugin_install 对真机缓存里的 0.7.1 包返回 id/dir/manifest，manifest 的 platforms 含 android 通过；安装入口能拉起系统文件选择器。vitest 51（manifest 48 + platform 3）、cargo manifest 8、tsc/eslint/prettier 干净。遗留：选择器里选 adb 推入 Download 的包报 Permission denied (os error 13)，同一包在应用缓存里 install 正常，疑为 shell 推入文件无 provider 读授权，待用户浏览器下载的真包复验。
