# 裁决 31 — 手机格式工具栏改判

## 决定

| 事项     | 裁决                                                                                                                                                                                                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 改判对象 | 手机端横滑格式栏（旧路径 `src/app/format-bar-phone.tsx`，已不存在；当时一条 `overflow-x:auto` 横排，UNDO＋12 键）——用户判「横滑不便、无层级、太丑」，**废**                                                                                 |
| 新形态   | 墨契三件套：常驻主条六键（插入 / 文本 / 列表 / 撤销 / 重做 / 完成）＋ 就地面板 ×2 ＋ 选中浮条（行内格式全走浮条）＋ 插入面板 2×5——规格与事件映射 = [《Textus-手机端工具栏改造方案》（归档）](../archive/2026-11-19-phone-format-toolbar.md) |
| 边界     | 只发既有菜单事件、零内核改动、文件住 `src/phone/`；**桌面侧 §7.8「墨契式浮层格式条先不做」已改判：不再等上游（2026-11-18 触发点撤销）**；桌面 = 停靠基底＋按需补缺；上游将来发布浮层格式条，手机维持自建                                    |
| 归属     | 裁决 30 手机端形态线的延长线（格式工具属「成熟移动形态」的一部分），非新战线                                                                                                                                                                |
