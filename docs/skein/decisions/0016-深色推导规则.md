# 裁决 16 — 深色推导规则

## 决定

**深色推导规则**：十屏不画深色板；深色 =「同一张纸在夜里」——纸墨基调互换、hair 改白系发丝线、阴影加深；此规则作为 A6 深色专项的验收依据
