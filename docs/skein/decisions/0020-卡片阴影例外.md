# 裁决 20 — 卡片阴影例外

## 决定

**卡片阴影例外**：可操作的提案卡 / 资产调用卡允许 `--shadow-1` 微阴影（画板 `0 0 0 1px hair + 0 1px 2px .05` 即其画法参照；上游 margin card 先例的扩展）；静态分组卡纯发丝线
