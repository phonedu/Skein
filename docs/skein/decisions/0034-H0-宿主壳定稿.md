# 裁决 34 — H0 宿主壳定稿

## 决定

来源：opencode 参考图（`opencode-h0-2026-11-21`，用户判「这版很不错」）＋随后几轮追加约束。实施与证据见
[归档](../archive/2026-11-21-h0-host-shell.md)。

| 事项     | 裁决                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 活动轨   | **删除**。导航不再有常驻图标列；顶栏“插件”按钮是插件页面与命令的唯一永久入口（QuickPick 过滤）。                                                                                                                                                                                                                                                                                                                                 |
| 桌面左栏 | **260** 视图列（2026-11-22 设计定稿从 280 收到 260），**今天 / 文件**两态；文件下再分 文件树 / 大纲 / 全文搜索。**不要插件页签**（顶栏已管）；搜索范围：左栏 = 库内文件与全文，顶栏 = 命令。                                                                                                                                                                                                                                     |
| 记一句   | 多端同一动作：手机今天页顶部**吸顶**“记一句…”；桌面/平板是视图列切换条右侧的小圆 +。**禁止悬浮 FAB、禁止底部主行动条**。                                                                                                                                                                                                                                                                                                         |
| 手机首页 | **今天**：当前交付 + 待确认 + 今天改动；不放“最近 / 全部笔记”（在文件）。顶部只有仓库名 chip、⋯（低频 sheet）、⚙；库页由今天页进入，顶部 + / ⚙，**同样无 FAB**。                                                                                                                                                                                                                                                                 |
| 右页边   | 桌面与平板 ≥840：**340 壳级按需栏**，两页签 = Agent（页边会话）/ 插件（`PluginListPane` 或插件视图）；关闭即归还宽度；手机与折叠不出现常驻第三栏，插件页整页打开。                                                                                                                                                                                                                                                               |
| 卡片     | **卡片侧边条一律禁止**（`::before` 竖条是硬禁）；分区用整条发丝线/留白，不用侧条。                                                                                                                                                                                                                                                                                                                                               |
| 选择浮条 | 手机保留 PH1 的 7 键选中浮条与格式栏，**不回退**；H0 不动编辑器工具栏。                                                                                                                                                                                                                                                                                                                                                          |
| 设置     | 手机 / 折叠 / 平板 = 全屏页（列表 → 推子页）；桌面 = **1040×720 弹窗**（2026-11-22 设计定稿）；顶栏 44px 玻璃条、只有“设置”+ ×，内容区不画页标题；左列 **260** 复用手机的分组列表，右列 content max **680**、左右 50 / 上下 28/32；每组为玻璃卡（`--shape-card` 18 / `--ui-surface` / `--shadow-card`，无描边），行 56/72，发丝线左起文字、右缩 16、末行无线；桌面开关 40×24，手机 48×28。多端同一套行与选中态。平板不得用弹窗。 |
| 按钮     | 动作按钮 / 图标按钮 = `--shape-s` 圆角矩形（裁决 17）；胶囊只留给 chips / tags / 状态徽章 / 设置值控件。                                                                                                                                                                                                                                                                                                                         |
| 手机栏   | 今天 / 库 / 设置 / 文档页共用一个顶栏行高 **56**（`--phone-bar-row`）、整条发丝线、48px 按钮、共用左向 chevron；仓库 switcher 一套配方（**无边框、无底色**，只有 28 图标底块 + body/600 + chevron；2026-11-22 用户复看后从“边框 + surface”改回无框）；分区标题统一 `.tx-section-label`（footnote / 600 / 0.08em / 不大写）。                                                                                                     |
| 触控     | 手机 44–48；平板 / 折叠（`data-platform="ios"/"android"`；**平板 chrome 是 `app`，不是 `mobile`**）上的视图列、今天行、右页边按钮同样 44。                                                                                                                                                                                                                                                                                       |
| 动效     | 面板类（右 340、侧栏）320 进 / 200 出；桌面设置弹窗 320 进 / 200 出（层在退场期间保持挂载）；手机页面推入 / 返回 320 spring（`motion-edge-in-end` / `motion-edge-out-end`）；浮层 / 菜单按 motion-tokens；**不给 `grid-template-columns` 或宽度做动画**；全部用 `--dur-*` / `--ease-*` 与 `--motion-travel`，reduced motion 归零。                                                                                               |
| AI       | 桌面/平板的 AI 默认在右页边（不再创建 AI 页签）；手机/折叠仍以整页 AI 呈现。                                                                                                                                                                                                                                                                                                                                                     |
| 插件页   | 桌面/平板：list 进右页边，webview / 流程页（确认中心）整页页签；手机：全部整页，Back 回上一页。                                                                                                                                                                                                                                                                                                                                  |
| 待确认   | 插件状态项（`ui.statusItem`）上报“N 条待确认”；宿主今天页与状态条只显示并跳转，不写业务逻辑。扩展页在所有形态可用（桌面/平板的插件管理入口）。                                                                                                                                                                                                                                                                                   |
