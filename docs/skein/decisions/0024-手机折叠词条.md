# 裁决 24 — 手机折叠词条

## 决定

**手机折叠词条**：手机资产折叠为「报价前·按触发匹配 + 全部资产」、笔记不进判断段——词条与桌面同名，分组可折叠（画板规格注记由「分组和桌面同名」改「同名折叠」）
