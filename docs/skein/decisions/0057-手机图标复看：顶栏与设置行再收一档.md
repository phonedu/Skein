# 裁决 57 — 手机图标复看：顶栏与设置行再收一档

## 决定

[裁决 56](0056-图标全局放大与加粗.md) 落地后，2026-11-23 用户复看手机端，再定两条：

1. **顶栏的设置 / ⋯ 和库图标统一到同一档**：`PhoneToday` 的 `.ptop-ic`、`PhoneHome` 的 `.ph-ic` 的 `--icon-scale` 从 **1.35 → 1.47**，与库/文件夹图标的 1.47 一致。之前顶栏动作是 1.35，库图标是 1.47；加上全局 1.3 后，库图标约 26px，而设置/⋯ 约 24/25px，视觉上像“只加粗、没变大”。统一后顶栏设置约 **26px**、⋯ 约 **27.8px**。
2. **设置行图标收小一档**：`.settings-phone-row-ic` 的 `--icon-scale` 从 **1.55 → 1.40**。17px 设计 × 1.40 × 1.3 × 10/11 约 **28px**（放大前的设计意图约 23–24px，复看前的 31.1px 太大）；62px 行内上下各留约 17px，仍是“比以前大、比现在小”。
3. `.ph-ic svg` / `.ph-vault .vic svg` 的固定兜底尺寸也乘 `--icon-growth`，避免没有内联尺寸的手绘/兜底图标被钉在旧值。

## 理由

- 顶栏三个图标在同一行，尺寸差 2px 时用户先看到“库图标变了、另外两个没变”；同一档后不会互相抵消。
- 设置行 31px 的图标占 62px 行高约一半，压住文字；28px 约占 45%，给上下各留约 17px 的呼吸，比放大前（设计意图 23–24px）仍然明显大一档。
- 这两处是手机端的局部值，不改变 56 的桌面/手机全局倍率；桌面的 1.1 和手机 1.3 不动。

## 影响

- 手机设置页的图标契约测试从 1.55 更新为 1.47（裁决变了，不是让测试迁就实现）。
- 顶栏按钮仍是 48px 触控区，只改图标绘制尺寸；不改变行高、按钮或布局。
- 桌面端不受影响。

## 来源

2026-11-23 用户复看手机端：“设置图标、⋯ 都没有变化，旁边的库文件库图标都有变化……31px 太大了，比以前的大、比现在的小就行。”相关：[裁决 56](0056-图标全局放大与加粗.md)、[裁决 36](0036-Slate-皮肤-v2-定稿.md)。
