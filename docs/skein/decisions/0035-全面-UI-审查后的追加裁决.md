# 裁决 35 — 全面 UI 审查后的追加裁决

## 决定

来源：opencode 全面审查（报告 `C:\Project\skein-plan-scratch\ui-audit-2026-11-22\REPORT.md`）；用户选 **P0 全做、P1/P2 全做**，总要求“样式必须保持一致”。P0 见 v6.16，下表是 P1/P2 的收口口径。

| 事项         | 裁决                                                                                                                                                                                                                                                                                                                                      |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 表面与发丝线 | 2026-11-22 设计定稿改为玻璃卡：`--ui-surface`（94% 白 / 90% 深色）+ `--shape-card` 18 + `--shadow-card`，不再用 1px 描边；对话框 = `--ui-bg` + 1px 边框 + `--shape-m` + `--shadow-dialog`。卡片内发丝线**从文字起点起、右缩 16、末行无线**（手机/桌面同一套渐变画法），颜色 `--ui-border` 100%。                                          |
| 按钮形态     | 组头工具统一：图标 = `.tx-icon-button`，需要文字的主作用 = `tx-button small`；动作/图标按钮一律 `--shape-s`；胶囊只给 chips / tags / 徽章 / 设置值控件。                                                                                                                                                                                  |
| 今天         | 行标题用文档标题（frontmatter `title` → 第一个 H1 → 文件名），id 降为 caption（`时间 · id`）；桌面行高 `--control-height-sm`，手机 62 写 / 56 绘；空态用 `--icon-tile-lg` + 标题 + 提示 + 一个按钮，不套卡片。                                                                                                                            |
| 视图列       | 今天/文件 = `Segmented equal`（同一滑块组件）；列脚一行：设置 + 文件视图的笔记数；文件下的子页签改叫 **文件树**（避免与“文件”分段重名，10 语言）。                                                                                                                                                                                        |
| 右页边       | 标题 `.tx-pane-title`，Agent 的 Memory/History/New 并进同一头部；触控端头部放不下标题时（`.right-panel-head:has(.right-panel-tools)`）**隐藏标题**，不显示截断的“Te…”。文档 < 480 时右页边改为**覆盖层**（不再挤压文档），340 宽、左侧阴影。                                                                                              |
| 扩展页       | 组头工具一种形态；主题卡的作者与安装数合并为一行 caption（“作者 · N 次安装”）。                                                                                                                                                                                                                                                           |
| 侧边竖条     | 壳层仍**一律禁止**。例外只给“引文/引用”语义：`agent-comment-quote`、`agent-comment-row-quote`、`agent-comment-suggestion`、`quick-ask-dock-quote`、`bottom-card-quote`、`agent-markdown blockquote` 与 turn-reply/chat-progress 的线程线，按文档 blockquote 对待；其他（thought、outline 的 thesis）改用缩进/`--ui-subtle` 面，不用竖条。 |
| 动效         | 行/按钮 hover 80ms 进、出即时（transition 只写在 `:hover`）；视图、右页边页面、设置页切换用 `motion-settle-in` 120ms（内容 keyed）；toast 退场 `motion-sink-out`（被挤掉的 toast 即时消失）；开关 thumb `--dur-base` spring、底色 `--dur-fast`；reduced motion 下 base/slow/settle/land/tuck 统一 150ms，分段滑块不滑动。                 |
| 触控         | 44 是**命中区**也是布局尺寸：文件行的 ⋯ 在手机/平板同为 44，且必须有基础按钮样式（不能露出浏览器原生按钮）；`.tree-tool` 同样补基础样式。                                                                                                                                                                                                 |
| FAB 遗留     | 手机 sheet 用 `--ui-overlay`（不再 60% 强遮罩）；库页底部 24；More sheet 不再重复“设置”。                                                                                                                                                                                                                                                 |
| 安全区       | 手机设置根列表靠 `.settings-phone` 的 `padding-top: --safe-top` 避开状态栏；推入子页是绝对定位层，必须用 `inset-top: var(--safe-top)` 自己补回（absolute 子元素从 padding box 起算，不吃父级 padding），否则“通用/外观”会顶进状态栏。2026-11-22 用户复看时发现并修正；真机实测 page.top = bar.top = 45px。                                |
