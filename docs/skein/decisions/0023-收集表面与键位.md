# 裁决 23 — 收集表面与键位

## 决定

**收集表面与键位**：桌面收集 = Dialog 行浮层（无暗层、Escape 关、焦点回原处），⌘⇧C 唤起（落地时与现有命令注册查重）；手机 = 底栏动作位，点开即 sheet（有暗层），不是第四索引轴
