# 裁决 29 — 十屏 IA 封存，小改宿主＋插件优先

## 决定

| 事项           | 裁决                                                                                                                                                                                                                                                                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 界面路线       | **小改宿主＋插件优先**：桌面以宿主 **v1.4.6-rc.3** 现状为基，笔记 Agent ＋资产闭环的全部功能走插件承载（《改造方案》§12.3 口径）；十屏 IA（§2.5）**推迟**到《改造方案》§8 阶段 0.5 理论验证通过后再议。修订对象 = 本清单 v1.2 的「十屏按屏开工」定档与《改造方案》§7.8 顺序（旧任务清单 §4 已迁[归档 §2.1](../archive/2026-11-19-task-list-archive.md)） |
| 壳改动         | C 组壳改动（top-view 三视图、今天 / 资产页、轨道首组）**从工作线删除**（`1c8e6377`，−939 行），不留分支；轨道回宿主原样，48px 柱上的双导航重叠随之消失                                                                                                                                                                                                   |
| 画板           | 旧十屏画板已于 2026-11-20 删除；裁决 29 的封存状态保留为历史（非权威、不施工、不勘误，用户判定其含凭空 / 错位成分）；「画板 > 平台规范」权威链停用，桌面以宿主现状为准。上游停止维护或 D0.5 通过时再议重启                                                                                                                                               |
| 手机端         | 手机界面**单独评估**（用户判宿主手机端「极度丑陋」）：挂 **D0 真机验证 / D3 多端入口**触发，不因本裁决新开工作线；旧画板 `ui-p-a/b` 已删除                                                                                                                                                                                                               |
| 平板手势       | **待平板 pass**：2026-11-19 用户口述——宽屏三栏暂保持现状（左缘拉出抽屉）；做平板布局时再定：内容区左→右滑开侧栏、边缘滑动交给系统返回（对应任务清单 A9）                                                                                                                                                                                                 |
| 已落地件的去留 | A 组设置浮层（§3）、A10 单岛平铺、A11 主题基色、侧栏最近 / 库段、视图状态条**全部保留**——宿主内的面级增改，已收口有测试，不属壳                                                                                                                                                                                                                          |
