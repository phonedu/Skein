# 裁决 15 — 两档灰修订

## 决定

**两档灰修订**（修订 §2.4）：正文 / 次要两档不变；第三档 faint 仅限 caption/footnote 级（12px）元信息，实现用 `color-mix(文字 45%, bg)` 派生，不新增硬编码色
