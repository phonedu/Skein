# 裁决 37 — 主题策略

## 决定

**界面皮肤由 Skein 管，主题只负责文档。** 详见 [《Textus-主题策略》](../specs/Textus-主题策略.md)。

| 层             | 规则                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------- |
| Skein 皮肤主题 | 少量、完整适配（皮肤 + 文档）；现阶段只有 Slate；以后从上游挑几个内置并完整改造。               |
| 文档主题       | 上游内置 + 导入主题：只改 `--doc-*` / `#write`；界面锁定当前 Skein 皮肤；主题选择器标“仅正文”。 |
| 自有主题系统   | 长期目标，现阶段完全不做；未来主题包可同时声明皮肤与文档。                                      |

阶段 1 的代码口径：导入主题不再派生/覆盖 `--ui-*`，允许列表拒绝 `--ui-*`；保留 `--doc-*` 与 `--theme-content-width` 推导；Prism 作为帧主题在阶段 1 决定降级为文档主题或做成第一个完整皮肤。插件 `appearance.setColors` 不得覆盖全局皮肤。**当前版本尚未实施该代码改造**（仍沿用上游行为），以本契约为下一阶段依据。
