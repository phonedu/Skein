# 裁决 64 — 库切换与移除只清列表

## 决定

| 事项     | 裁决                                                                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 入口     | 库名（带 chevron 的 chip）点开切换面板：桌面在按钮下方下拉（`.vault-panel`），手机在今天/文件页从底部弹 Sheet（§9 已定的库切换底部面板）。                                                                               |
| 列表     | 第一行是当前打开的库：带勾、不可切换、没有垃圾桶；其下按最近顺序列出选过的库（名称 + 路径），点一行即切换；底部“添加库…”进系统文件夹选择器。                                                                         |
| 移除     | 每行垃圾桶只把该库移出最近列表（Rust `recentFolders`，桌面 `File > Open Recent` 同源同步）。**不删文件、不删文件夹、不删 `.textus` 项目设置、不清同步绑定与凭据、不动草稿和页签。**                               |
| 存储     | 最近库沿用 Rust 的 `recentFolders`（最多 5）；手机打开库也写入；`content://` 等 SAF URL 不按文件系统存在性过滤，重启后按持久授权重新打开。                                                                             |
| 桌面原生 | `File > Open Recent > 文件夹` 保留，与面板读同一份列表。                                                                                                                                                                 |
| 不做     | 多库同时挂载、多窗口库栏、命令面板“切换库”入口；当前库不能被移除。                                                                                                                                                     |

## 理由

打开过的库不该再走一遍文件夹选择器（手机上 SAF 选择尤其费事）；“移除”只该整理列表，不该有数据含义。当前库不在列表里时再出现一行可删的“当前”，会让删除看起来没生效，所以当前行不给垃圾桶。

## 影响

- `src-tauri/src/commands/recents.rs` 的 `add_recent_folder` / `remove_recent` / `list_recent_folders` 改为桌面与手机共用；`still_there` 放行 URL。
- 前端 `platform/ipc-files.ts` 的 `recents` 与 `session.addRecentFolder` 走同一组共享命令；桌面菜单与手机面板同源。
- 桌面 `Sidebar`、手机 `PhoneToday` / `PhoneHome` 的库名统一由 `vaults/VaultButton` 渲染并打开 `vaults/VaultPanel`。

## 来源

2026-11-25 用户口述手机端做法（当前库 + 以前选过的库 + 添加库 + 每行垃圾桶，只清信息不删文件），并确认桌面按桌面习惯做成按钮下方下拉面板。
