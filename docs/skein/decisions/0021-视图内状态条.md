# 裁决 21 — 视图内状态条

## 决定

**视图内状态条**：每屏底部脚注（「Markdown 就是全部·共 128 篇」「草稿 3·未激活」等）定性为**视图内状态条**组件（左说明 / 右计数两槽），不是全局 chrome；surface 模板补一行（B 组 rebase 时同步上游模板表）
