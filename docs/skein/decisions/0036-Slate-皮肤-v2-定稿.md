# 裁决 36 — Slate 皮肤 v2 定稿

## 决定

来源：Obsidian 桌面/手机参考 + 苹果玻璃表面参考 + Slate 色板。设计板与截图保留在 `C:\Project\skein-plan-scratch\obsidian-design-2026-11-22\`（**不入仓**；旧画板仍不复活）。

| 事项     | 定稿                                                                                                                                                                                       |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 皮肤     | 默认 **Slate**；chrome 固定 Slate，不随文档主题变暖；浅色 `#F0F1F3` / 侧栏 `#E9EBEF` / 卡片 94% 白 / 文档 `#FCFDFE`；深色 `#0D1117` / `#11161D` / `#161B22`。                              |
| 卡片     | 静态卡 = `--ui-surface` + `--shape-card` 18 + `--shadow-card`；无描边；长列表不做实时模糊。                                                                                                |
| 桌面设置 | 1040×720；左导航 260；内容 max 680；顶栏 44px 玻璃条、只有“设置”+ ×；内容区无页标题；行 56/72；发丝线左文字起点、右缩 16、末行无线；桌面开关 40×24。                                       |
| 桌面壳   | 左栏 260；正文文字列约 700–712（1440 宽、右栏关闭）；右页边 340；当前交付与“今天改动”同为裸行（文件图标 + 标题/路径），不再单独做白卡；侧栏“最近”与文件树同一套 28px 裸行 + 文件类型图标。 |
| 选中态   | `--ui-selected` 底 + accent 图标 + 600；桌面导航、文件页签、右页边页签、手机库当前文件一致；手机库在浅色页上追加 8% accent 淡染，保证 `#EEF1F5` 在 `#F0F1F3` 上可见。                      |
| 手机     | 今天/库/设置列表/外观子页统一玻璃卡；裸 22–24 线性图标；搜索浅色裸行、深色淡填充；行 56/62、开关 48×28；记一句主卡吸顶、圆形 accent 加号；无 FAB。                                         |
| 平板     | 与桌面同构缩窄；左栏 260；设置全屏、内容 660 居中；右栏按需 340。                                                                                                                          |
