# 分享卡片导出（图片卡片/长图）

> **2026-11-28 用户定方向**：做一个 md2card 式的分享图片卡片功能——导出图片时提供多种模板（备忘录、圈线本等样式），设置可自定义，用作发图。同日实测：**纯插件可做完整版，不需要宿主能力**。同日开工（SH1 doing）：提案转正式规格，界面设计见 §5。
>
> 插件边界见 [plugin-api.md](../../dev/plugin-api.md) 与 [plugins/permissions.md](../../dev/plugins/permissions.md)；界面按 [界面契约](../specs/界面契约.md)。

## 1. 结论

| 环节 | 归属 | 依据 |
| --- | --- | --- |
| 模板、实时预览、自定义设置 | **插件（SH1）** | 纯渲染；模板高频可变，数据化后持续加不用发版 |
| HTML → PNG 栅格化 | **插件页面** | 沙箱内 foreignObject→canvas 实测通过（§2） |
| 导出入口、保存对话框、写文件 | 宿主现有 API | `export.registerFormat`（1.4.4+） |

与[视频笔记与媒体宿主能力](../proposals/视频笔记与媒体宿主能力.md)正好相反：视频的媒体引擎难且通用，要进宿主；卡片导出没有特权需求，"难"在模板设计——恰恰适合插件迭代。

**对标（2026-11-28 定）**：醒文（XingText，iOS/Android 文字卡片应用）为体验基准；能力对齐它的体系，但设置组织不照搬——按"笔记 → 卡片"的内容驱动重排成五组（§4.1）。定位差异：醒文是独立编辑器（把文字粘进去），SH1 是**从 Textus 笔记直接导出**——笔记本来就有 Markdown、front matter、图片和主题，卡片自动继承标题/作者/日期/来源，不用重新粘贴。醒文的"链接一键提取"不进 SH1（归 CP1 网页剪藏线）。

## 2. 关键实测（2026-11-28）

- **入口现成**：`export.registerFormat`（API 1.8 / Textus 1.4.4+）在「文件 › 导出」注册 PNG 格式；插件 `export({ markdown, html, path })` 返回 `Uint8Array`，Textus 弹保存框并写文件（`src/export/plugin-export.ts`）。
- **内容白送**：宿主调 `format.run` 前已用 `images: "inline"` 构建独立 HTML——**本地图片已内联 data: base64**、公式已渲染；插件不碰文件系统就拿到所见即所得的内容。
- **栅格化全通过**（与插件页面完全相同的 sandbox + CSP，Chromium）：HTML → `XMLSerializer` → SVG `foreignObject` → data: URL → `<img>` → canvas → `toDataURL`。
  - 640px 卡片 @2x：1280×633 PNG（70KB），**画布未污染**，像素可读；
  - 长图 640×6000 @2x：1280×12000 PNG（466KB）；
  - 超长 640×20000 @2x：1280×40000 PNG（1.5MB）。
- 实现同 html-to-image（MIT，可打包）：克隆节点 → walk 内联 computed style → 序列化。注意 `XMLSerializer` 会自动带 xhtml xmlns，不要手工拼。
- 证据：`C:/Project/.scratch/card-export-spike/`（仓库外，任务关闭时删）。

## 3. 范围

- 做：
  - 插件「分享卡片」标签页：模板选择、实时预览、五组设置（样式/内容/版面/外观/字排，见 §4.1）。
  - 两条导出路径：预览页按钮 → `files.write` 写进库（如 `附件/卡片/`）；「文件 › 导出 › 图片卡片」→ 保存框任选位置。
  - 模板数据化（JSON / token），官方内置 2–3 个（备忘录、圈线本、暗色小报），支持用户自定义。
  - 长图与分页卡片两种模式（分页躲开移动端 canvas 上限，也更适合发群/朋友圈）。
- 不做：
  - 改宿主导出管线或放宽沙箱。
  - 剪贴板图片复制（`env.writeClipboard` 仅文本；需要核心新 API，后议）。
  - 网页/在线内容转卡片。
  - 手机版 v1（先桌面）。

## 4. 设计要点

### 4.1 设置体系（2026-11-28 核对醒文截图后改定）

**组织自成一派，不照搬醒文的画布装饰器分类。** 醒文是"空白画布上装饰"（模版/布局/背景/纹理/文字/尺寸），SH1 是"笔记 → 卡片"，按内容驱动分五组：**样式 / 内容 / 版面 / 外观 / 字排**；导出动作不占设置组。能力与醒文一一对齐，归类按我们的心智走。每项改动实时刷新预览；「设为默认」把当前组合存回插件设置。

- **样式**（成品预设，选了就能用）：内置 2–3 个（备忘录、圈线本、暗色小报），每个=版面+外观+字排的组合。醒文的模板商店（科普/书摘/句子/期刊/封面/套装）不搬，v1 只内置。**候选内置模板池（2026-11-28 记录，v1 从中挑 2–3，其余随版本加）**：备忘录（引号起手、纸感）、圈线本（横线圈线）、杂志风（头图+大标题，3:5）、期刊（封面+摘要+元数据行）、拍立得（照片+手写边注）、手写笔记（横线信纸+楷体）、日历式（大日期头）、暗色小报（深底白字+强调色）、树影（光影叠层覆盖）。
- **内容**（Textus 的差异化所在）：标题、作者、头像、日期、**字数**、**阅读时长**、来源（front matter 的书名/链接）、水印文字——显隐开关 + 自动填充。醒文这些靠手填，SH1 从 front matter 与文档统计自动来，零粘贴。
- **版面**：比例（**自适应=长图 / 3:4 / 3:5 / 4:3 / 1:1 / 2:3**，社交分享主比例 3:4）、分页方式（长图/分页卡片）、**边距密度（紧凑/标准/宽松 + 滑杆）**、**圆角**、边框样式（无/细线/卡片/手机边框…）、排版预设（标题在上/引号起手/角标式…）。全部 v1。
- **外观**：背景（纯色跟随主题→v1；渐变、撞色、自定义图片 data: 内联→v1.x）+ 纹理（**窗影、树影**、纸纹布纹、格线/点阵/织纹/蜂巢，各带**透明度**滑杆→v1.x，手帐/文艺风的差异化大头）+ 强调色（跟随 `--doc-accent`→v1，色板覆盖→v1）。
- **字排**：字体栈（系统黑体/宋体几档→v1；**开源字体 2–4 款** data: 内嵌进 SVG→v1.x；醒文的"+ 导入字体"不做，版权与体积坑）、字号、**行高/字距/段距**滑杆（醒文默认 150/100/0，v1）、文字颜色。
- **导出**（预览页动作区，不占设置组）：倍率 1x/2x、保存位置（库内附件 / 「文件›导出」另存）。水印的位置与透明度随纹理库一批（v1.x）。

醒文 → SH1 对照：模版→样式；布局(边框/排版/显隐)→版面+内容；背景+纹理→外观；文字→字排；尺寸→版面(比例)+导出(倍率)。

### 4.2 其他

- 权限：`editor.read`（读文档）、`files.write`（预览页导出写库用；只走 registerFormat 路径则不需要）。
- 平台：先 `desktop`；手机等触屏预览与 canvas 内存另评。
- 文案十语言；模板用界面 token，不写死颜色。
- 栅格化注意：超大文档强制分页提示；自定义字体需以 data: 内嵌进 SVG；分页是移动端的正解。
- **分页质量**（醒文"智能长文分割"是它的核心卖点）：v1 按高度 + 段落边界切；质量项：标题不孤行、列表/代码块不拦腰拆、引用块跟随正文。

## 5. 界面设计（大概样式，v1 桌面）

> 只定布局与交互，不画终稿；实现时全部走 [界面契约](../specs/界面契约.md) 的 token（`--ui-*`/`--doc-*`/`--shape-*`/`motion-*`），不写死颜色与字号。插件页=普通标签（裁决 67）。
> **布局草样（HTML，桌面+手机并排，用宿主 Slate 令牌绘制）**：定稿骨架 = `C:/Project/.scratch/sh1-design/sh1-mockup.html`（五组右栏顶固定+控件滚动已可滚动演示，预览辅助自 V2 合并）；`sh1-mockup-v2.html`（五组整宽分段带方案）被 2026-11-28 裁决否弃，仅留对比——任务工作产物，任务关闭时随 scratch 清理；本节文字才是长期真相。

**入口**：

1. 命令/插件菜单「分享卡片」→ 打开预览页标签（主入口）；
2. 「文件 › 导出 › 图片卡片」→ registerFormat 直通导出，无预览（副入口）。

**预览页布局**（桌面 ≥1000px，左预览右设置；窄窗时设置栏收到预览下方）：

```text
┌──────────────────────────────────────────────────────────────┐
│ 分享卡片 · {文档名}                    [恢复默认] [设为默认]      │
├───────────────────────────────────┬──────────────────────────┤
│                                   │ [样式|内容|版面|外观|字排] ← 五组分段切 │
│        ┌───────────────┐          │ ──────────────────────   │
│        │  卡片预画（实时） │          │ 样式: 模板缩略图 2–3 个横排 │
│        │  模板/设置改动    │          │ 内容: 显隐开关列表+水印文字框 │
│        │  即时重画        │          │ 版面: 比例段选+密度/圆角滑杆 │
│        │               │          │ 外观: 纯色色板+强调色       │
│        └───────────────┘          │ 字排: 字体栈段选+行高字距滑杆 │
│   分页模式:  ● ○ ○   ‹ 页 1/3 ›   │                          │
├───────────────────────────────────┴──────────────────────────┤
│ [长图|分页] ←分段   倍率 [1x|2x]        [保存到库]  [另存为…]    │
└──────────────────────────────────────────────────────────────┘
```

**要点**：

- **2026-11-28 用户定**：五组分段**固定在设置栏顶部**（sticky，不随内容滚动）；控件区内容过长时独立上下滚动。
- 预览即真实卡片 DOM（不是缩略图）：改设置=改 DOM，栅格化直接克隆它，所见即所得。预览右上角常驻自动元数据角标，右下角缩放（适配/100%/200%，自 V2 合并）。
- 五组控件一一对应 §4.1；组内不做二级页，控件直接平铺。
- 底部动作区常驻：长图/分页与倍率是"出图参数"不是"样式"，所以不进五组；「保存到库」走 `files.write` 写 `附件/卡片/`，「另存为…」走 `export.registerFormat` 的保存框。
- 分页模式预览显示页点与翻页；导出时按页出多张 PNG（一次写多文件走库内路径）。
- 「设为默认」把当前五组组合存插件 settings；「恢复默认」回到出厂模板默认。
- 控件全用 Textus 现成件：`tx-segmented`（分段）、`tx-button`（按钮）、`tx-card`（模板缩略卡）、滑杆与开关用设置页同款。
- 手机（后议，见 §7）：预览在上、设置收进底部 sheet（可拖三档：收起/半开=默认/全开），桌面布局不做等比缩小。

## 6. 验收

- 内置模板 ×（长图/分页）导出 PNG，@2x 清晰；中文、代码块、图片、公式渲染正确。

- 显隐开关逐项生效（标题/LOGO/作者/引号/页码/日期/字数/来源）。
- 「文件 › 导出」路径弹保存框、写入成功；预览页路径写入库内附件目录。
- Windows（WebView2）全过；**macOS WKWebView 真机补验 foreignObject**（未验项，见 §7）。
- 十语言通过；插件关停、卸载不残留。

## 7. 未决与触发点

- **WebKit（macOS/iOS）foreignObject 渲染**：本机只有 Chromium 可测，WebKit 未验；有坑则退化（直接 canvas 绘制 / iOS 分页更小）。macOS 真机验证后再排macOS/iOS。
- **剪贴板图片复制**：需要核心新 API（`env.writeClipboard` 文本 only）；v1 用"保存文件 + 手动粘贴"顶住，之后按需提。
- **醒文截图未覆盖的两页**：文字 › 颜色、纹理 › 效果/渐变 的具体选项没截到，做 v1.x 纹理时对照补；选项名以 Textus 自己的措辞翻译，不照抄。
- **模板分享格式**：用户自定义模板是否可导入导出/分享（醒文是商店+套装）；等真实需求再定。
- **SVG/PDF 导出**：PNG 够 v1；SVG 链路顺手（foreignObject 本身是 SVG），有需求再看。
- **手机**：触屏预览交互与 canvas 内存；随视频线（VID1/MED1）之后的手机评估一起看。
