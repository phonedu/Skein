# 上游 1.4.7 接入顺序

## 范围

- 做：把上游稳定 tag `v1.4.7` 整体合入 fork，止住 1.4.6 → 1.4.8 的分叉债；合并后按 B7 清单验收界面功能，缺的再补。
- 不做：不追 `v1.4.8-rc.1` 或任何 rc；不在合并分支夹带新功能；不把 fork 已删的 `docs/design/`、`docs/images/`、`ROADMAP*` 等路径带回来。

## 结论

**先整体接入，再按清单验收。** 2026-11-25 用户改定：上游更新很积极，1.4.8-rc.1 已经出现；继续按功能逐项择取会让 fork 基线一直停在 1.4.6，每个稳定版都要重复解同一批冲突。1.4.7 是一次性把基线推到 1.4.7 的窗口，值得先付这笔合并成本。

试合并证据（2026-11-25，临时 worktree，已清理）：

- `v1.4.6..v1.4.7`：18 个提交、574 个文件、约 2.2 万行新增。
- 与 fork 冲突 **51 处**，集中在 `src/app/frame/sidebar-tabs.tsx`、`useSidePanels.ts`、`src/app/islands/DocumentIslands.tsx`、`src/app/tabs/useTabState.ts`、`src/editor/editor-menu.ts`、移动端 CSS、`src/i18n/locales/zh-Hant.ts`、插件平台与 `src-tauri/Cargo.toml` / bindings。
- 80 个 fork 已删路径会被 tag 带回（`docs/design/`、`docs/images/`、`ROADMAP*`、旧 release notes 等），必须在 `upstream:clean` 里继续删掉。

## 顺序

1. **已完成**：`skein-1.4.6-slate.11` 从 `2d2fc929` 发布，保住当前可回退的安装包。
2. **B8 整体接入 v1.4.7**（2–4 天）
   - 从 `base-ui-settings` 开独立上游分支，走 `upstream:status` → `upstream:plan -- v1.4.7` → `upstream:start --apply`。
   - 解决 51 处冲突：保留 fork 的 H0 宿主壳、Slate 皮肤、手机壳层和同步页；上游带来的编辑器性能、44pt 触控、拖放、插件 API 1.10 按上游实现收下。
   - 用 `upstream:clean --apply` 让已删路径保持删除；`upstream:verify` 后跑 typecheck/lint/格式/全量单测/cargo，再做桌面构建和 Android 冒烟。
   - `upstream:record` / `upstream:finish --apply` 记下基线；合并分支不夹带新功能。
3. **B7 验收与补齐**（1–2 天）
   - 按 `research/上游1.4.7界面功能盘点.md` 逐项验收：路径补全、Mermaid 错误原因、插件商店分类/“仅电脑可用”、插件页菜单选择、拖文件进文档、文件树接收系统文件/插入链接、插件页触控。
   - 已有功能的记录证据；只有合并后确实缺失的才补，补时沿用上游提交，不重写。
4. **D 组随 1.4.8 稳定版**
   - 转场、内存、Mac/Linux/iOS 专属等不在本次合并里逐项追；等 1.4.8 正式版再按同一流程评估。
