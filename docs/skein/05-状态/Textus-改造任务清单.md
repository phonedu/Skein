## 8. 偏差 / 缺口

- **D-1（2026-11-19，PH1 真机；当日已解决）**：Android 图片选择器返回 `content://com.android.providers.media.documents/...`；规格假设 `pickImageFile` + `copyToImageFolder` 能直接读，实际 `read_binary_file_base64` 只走 `fs::read`，图片实际插入失败。处置：`textus-files` 新增 `pick_image`（带文件名）＋ `read_data`（ContentResolver），`pickImageFile`/`readBinaryFileBase64` 走插件；真机 actual insertion 通过（draft assets URL）。H1 不再承接该项。
- **S2/S3 已归档**：[S2 验收](../archive/2026-11-20-s2-acceptance.md)、[S3 移动端](../archive/2026-11-21-s3-mobile.md)、[S6 迁移](../archive/2026-11-20-s6-migration.md)。正文不再保留完成项。

  - **S3b**：阿里云/七牛真桶仍待各自凭据，不阻塞后续。
  - **移动端加密**：S3 v1 用明文仓库；内置/插件真机加密同步仍未做，归后续移动端加密项。
  - **传输预算**：32 MiB 上限未强制，归 S5。
  - **超时**：transport 20 s 连接 / 180 s 总超时已配置，未做 180 s 真实挂起测试。
- **全量 `npm run check`（2026-11-21）**：`.ryugi/`、`store/`、`.tmp-s1-s3/` 已列入 ESLint/Prettier 忽略（本机草稿/同步夹具，非源码）；typecheck、lint、全量 vitest（585/588 文件，3 skipped）、prettier、check:repo 全绿；`cargo test --lib` 1112 passed。
- **下一步**：B3 华为真机 smoke（待手机解锁）→ S2c 文档身份 spike → D1 资产链；S3b 待凭据。
- **传输预算（2026-11-20）**：协议写 `TRANSFER_BYTES = 32 MiB`；内置引擎目前按文件顺序传输，单文件峰值可达 128 MiB，未强制池化预算。归入 S5 硬化或 S2-2 一并评估。

- **上游文档失效链接（已关闭，2026-11-21 复核）**：`check-links` 现报 166 个 Markdown 文件全部相对链接可达。历史 19 处断链由 `f92766b0` 的检查器豁免 fork 已删除路径解决；不要再改上游文档或检查脚本。
