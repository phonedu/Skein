## 1. 当前判断（2026-11-19）

**当前分支**：`base-ui-settings`；基线 = 上游 v1.4.5（`c467a7b5` 已并线）。手机线是当前最活跃的工程线；同步评审完成、`06` 部分已定，**尚无代码**；整体仍待 S0a supersede 落档。

**顺序**：

1. **Now（4–6 周；单人，S0 文档可并行）**：D0 Android 真机验收 ＋ 同步 P0 文档（S0a–S0d）＋ 宿主前置（H1–H8）。
2. **Next（4–9 周；S1 与 D1 择一，D0.5 并行）**：同步插件多端 spike（S3 → WebDAV）或 D1 资产闭环剩余；PH3/PH4 手机核查；D0.5 理论验证。
3. **Later（3–6 个月；按人周估算）**：内置同步桌面 MVP（含多库）→ 移动端 → 局域网 Hub → 硬化；D2 受控写入、D3 多端完善。
4. **Ongoing**：上游跟随（下一 tag v1.4.6）、设置遗留、手机打磨、分支收口、文档维护。

**为什么不是直接开内置同步**：内置是 12–22 人周的长项目；插件 spike 只要 1–3 周，能先拿到手机能否可靠上传/下载的真实数据。插件 spike 的前置是宿主文件层（H 组），而这些同时是 D0/D3 的验收项——先做它们不是为同步单独铺路。
