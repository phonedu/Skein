## 8. 偏差 / 缺口

- **第三方 WebDAV**：坚果云/Nextcloud 等仍无账号凭据，外部阻塞；S2c-V2 也等它。
- **S3b / S3q**：七牛凭据已验证（南区域；无条件读写通过），S3 条件写不支持（`unsafeServer`），阿里云按用户决定不测；原生 `insertOnly` 适配列 S3q，D1f 后做，当前只用缤纷云。
- **移动端加密**：S3 v1 用明文仓库；内置/插件真机加密同步仍未做，归后续移动端加密项。
- **超时**：transport 20 s 连接 / 180 s 总超时已配置，未做 180 s 真实挂起测试。
- **传输预算（2026-11-20）**：协议写 `TRANSFER_BYTES = 32 MiB`；内置引擎目前按文件顺序传输，单文件峰值可达 128 MiB，未强制池化预算。归入 S5 硬化或 S2-2 一并评估。
- **服务器时间（2026-11-20）**：协议要求服务器 `Date` 优先、设备时钟只作 fallback 并 clamp；内置引擎目前只用本地 `Utc`，`ObjectStore` 没有 `now()`。归入 S5。
- **密钥静态保护（项目级）**：`sync_secrets.json` 沿用 `provider_keys.json` 的 `0600`（Unix）写法；Windows 仅依赖用户目录 ACL，尚未接 DPAPI/Keychain。若要更强保护，应作为全项目密钥存储改造，而不是只改同步。
- **WebDAV 真服务**：本轮不做（无 WebDAV 服务）；S3（Bitiful）带 id 已过，七牛 Kodo 待凭据。
- **同步页俄语存量标签**：S2c-V1 发现 `Folder / Synced. / Last synced / Service / Server address / Remote folder / Save connection` 仍为英文；归同步文案清理，不阻塞 D1。
- **H9 SAF 能力群**：2026-11-21 决定**关闭**；S3 v1 的 App Documents + 普通路径已覆盖现有需求，`content://` 不做，除非出现真实用户场景再重开。
- **观察期锚点（D1b）**：卡片没有 `activated_at`，确认中心的「观察期 / 未验证」按 `created_at` 计；D1f 指标若需要真激活时间再补字段。
- **确认中心手机入口**：D1b 的窄屏页已在桌面 WebView 以 344 CSS px 验过；Android/iOS 上打开确认中心仍归 D3 宿主壳入口（与 D1a 列表同一个入口）。
- **其余偏差暂无。** 下一个真实偏差按 [AI 协作纪律 §六](../01-纪律/AI协作纪律.md) 记「D-2」。
