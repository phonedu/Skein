### Improved

- **A phone's bottom sheets follow the finger and leave from where it lets go**: pulling a sheet down no longer snaps it back up before closing, and a short pull springs back smoothly.

### Fixed

- **File icon themes reach the file tree**: a theme picked in Settings › Appearance draws the sidebar's icons, light and dark, and one chosen before the window opens is there at once.
- **Custom AI endpoints are back in Settings › Models**: add one, test it, list its models, save, edit and remove it, each beside the built-in providers.
- **Ask before copying files dropped onto the file tree is back in Settings › General**, so ticking "Don't ask again" in the copy dialog no longer has no way back.
